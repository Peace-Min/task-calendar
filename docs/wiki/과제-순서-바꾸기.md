# 과제 순서 바꾸기

'🏷️ 내 과제'(예전 이름 '과제 관리')에서 과제의 순서를 정하면 **보고서에 과제가 나오는 순서**가 그대로 따라갑니다. 필터와 과제 선택 상자의 순서도 같습니다.

> 적용 버전: v0.19.x 이후

## 바꾸는 법

1. 상단 **🏷️ 내 과제**를 엽니다.
2. 각 과제 줄 오른쪽의 **▲ / ▼** 를 누르면 한 칸씩 위나 아래로 옮겨집니다(관리 화면의 순서 버튼과 같은 모양).
   - 맨 위 과제의 ▲, 맨 아래 과제의 ▼ 는 흐리게 보이고 눌러도 바뀌지 않습니다. 마우스를 올리면 "맨 위입니다", "맨 아래입니다"가 나옵니다.
   - 누를 때마다 **바로 서버에 저장**됩니다. 따로 저장 버튼은 없습니다.
   - 키보드로도 됩니다. 누른 뒤에도 포커스가 같은 버튼에 남아 있어 Enter/Space 로 이어서 옮길 수 있습니다.
   - 서버 연결이 끊긴 동안에는 옮겨지지 않습니다(안내가 한 번 뜹니다).
3. 목록에는 개인 과제와 공식 과제가 섞여서 실제 순서대로 보입니다(공식 과제에는 표시가 붙어 있습니다).

## 순서가 반영되는 곳

| 곳 | 반영 |
|---|---|
| 보고서(일간, 주간, 기간 취합, 복사, 회사 전송) | 과제 행이 이 순서로 나옵니다 |
| 상단 과제 필터 | 이 순서 |
| 새 기록, 빠른 추가, 검색의 과제 선택 상자 | 이 순서 |
| 할 일 편집의 과제 선택, 데이터 내보내기 | 이 순서 |

## 바뀐 점 (2026-10-02)

- (2026-10-06) 잠시 끌어서 옮기는 방식을 썼다가, 관리 화면과 같은 **▲ / ▼ 버튼**으로 통일했습니다(줄 오른쪽, 수정 앞).

## 예외

- 이름이 '기타'인 과제와 과제를 정하지 않은 기록(미분류)은 보고서에서 **늘 맨 뒤**에 나옵니다.
- '공식 과제(DB) 찾아보기' 화면은 회사 전체 과제 목록이라 이 순서와 관계없습니다.
- 새로 추가한 개인 과제와 새로 편입한 공식 과제는 맨 뒤에 붙습니다.

## 자주 묻는 것

- **다른 PC 에서도 같은 순서인가요?** 네. 순서는 서버에 저장되므로 다른 PC 에서 로그인해도 같은 순서로 보입니다.
- **서버 연결이 끊겼을 때는?** 순서를 바꿀 수 없습니다("서버에 연결되지 않아 지금은 편집할 수 없습니다"). 연결이 돌아오면 다시 됩니다. 자세한 내용은 [서버 연결이 끊겼을 때](서버-연결이-끊겼을-때)를 보세요.
