# 과제 순서 바꾸기

'🏷️ 내 과제'(예전 이름 '과제 관리')에서 과제의 순서를 정하면 **근태 보고와 취합에 과제가 나오는 순서**가 그대로 따라갑니다. 필터와 과제 선택 상자의 순서도 같습니다.

> 적용 버전: v0.19.x 이후

## 바꾸는 법

1. 상단 **🏷️ 내 과제**를 엽니다.
2. 과제 줄 왼쪽의 **⠿** 를 누른 채 위아래로 끌어 원하는 자리에 놓습니다.
   - 마우스 없이 옮기려면 줄 오른쪽 **⋯** 메뉴의 **순서** 줄에 있는 그림 단추(맨 위로, 위로, 아래로, 맨 아래로)를 씁니다. 맨 위 과제는 맨 위로와 위로가, 맨 아래 과제는 아래로와 맨 아래로가 흐리게 보입니다.
   - 창이 아주 좁으면 ⠿ 는 숨고 ⋯ 메뉴로만 옮깁니다.
   - 옮길 때마다 **바로 서버에 저장**됩니다. 따로 저장 버튼은 없습니다.
   - 서버 연결이 끊긴 동안에는 옮겨지지 않습니다(안내가 한 번 뜹니다).
3. 목록에는 일반 과제, 기본 과제, 공식 과제가 섞여서 실제 순서대로 보입니다(구분 열에 공식, 기본, 일반이 보입니다). 목록의 나머지 기능은 [내 과제와 과제 추가](내-과제와-과제-추가)를 보세요.

## 순서가 반영되는 곳

| 곳 | 반영 |
|---|---|
| 근태 보고(일간, 주간), 근태 취합(과제별 글, 월간 보고 문서) | 과제 행이 이 순서로 나옵니다 |
| 상단 보기(과제 필터) | 고른 과제와 새 기록의 기본 과제는 이 순서(팝업 목록은 기록 많은 순) |
| 일정 입력 창(일정, 할 일), 검색의 과제 선택 상자 | 이 순서 |
| 데이터 내보내기 | 이 순서 |

## 바뀐 점 (2026-10-02)

- (2026-10-06) 잠시 끌어서 옮기는 방식을 썼다가, 관리 화면과 같은 **▲ / ▼ 버튼**으로 통일했습니다(줄 오른쪽, 수정 앞).
- (v0.25.0, 2026-10-30) 줄의 버튼을 ⋯ 하나로 모으면서 ▲ / ▼ 는 없어지고, ⠿ 끌기와 ⋯ 메뉴의 순서 항목으로 바뀌었습니다.

## 예외

- (2026-10-07부터) '기타'도 다른 과제처럼 이 순서를 따릅니다. 예전에는 '기타'와 과제를 정하지 않은 기록(미분류)이 늘 맨 뒤였지만, 이제 미분류가 없고 기타는 [기본 과제](기본-과제-휴가와-기타)입니다. 맨 뒤에 두려면 ⋯ 메뉴의 맨 아래로를 쓰세요.
- 과제 추가 창의 공식 과제 표는 회사 전체 과제 목록이라 이 순서와 관계없습니다. 그 화면은 관리자가 정한 구분 안 No 순서를 따릅니다([공식 과제 순서와 거르기](공식-과제-순서와-거르기)).
- 새로 추가한 일반 과제와 공식 과제는 맨 뒤에 붙습니다.

## 자주 묻는 것

- **다른 PC 에서도 같은 순서인가요?** 네. 순서는 서버에 저장되므로 다른 PC 에서 로그인해도 같은 순서로 보입니다.
- **서버 연결이 끊겼을 때는?** 순서를 바꿀 수 없습니다("서버에 연결되지 않아 지금은 편집할 수 없습니다"). 연결이 돌아오면 다시 됩니다. 자세한 내용은 [서버 연결이 끊겼을 때](서버-연결이-끊겼을-때)를 보세요.
