# 창 버튼과 트레이

위젯 맨 위 제목줄 오른쪽의 버튼과, 트레이를 켰을 때 닫기 동작을 정리했습니다.

> 적용 버전: v0.19.x 이후. 창 버튼(최소화, 최대화)과 바뀐 '맨 앞에 띄우기'는 2026-10-16 개발판부터.

## 제목줄 버튼 (왼쪽부터)

| 버튼 | 이름 | 하는 일 |
|---|---|---|
| 겹친 창 아이콘 | **맨 앞에 띄우기** | 크기와 위치는 그대로 두고 위젯을 **다른 창들 위에** 띄웁니다. 켜져 있으면 버튼 바탕이 눌린 색입니다. 다시 누르거나 **Esc** 를 누르면 풀립니다. ☰ 메뉴에도 같은 항목이 있습니다 |
| 핀 | 바탕화면 부착 | 위젯을 바탕화면에 붙이거나 뗍니다 |
| ☰ | 위젯 메뉴 | 맨 앞에 띄우기, 설정, **종료** 등 |
| (구분선) | | |
| ─ | 최소화 | 작업 표시줄로 내립니다. 트레이를 켠 일반 창 모드에서만 보입니다 |
| □ | 최대화 / 이전 크기로 | 그 창이 있는 모니터를 **작업 표시줄을 가리지 않는 크기**로 채웁니다. 최대화 중에는 글리프가 겹친 사각형으로 바뀌고, 누르면 최대화 직전의 위치와 크기로 돌아갑니다 |
| ✕ | 닫기 | 아래 '트레이와 닫기' 참고. 마우스를 올리면 빨간 바탕입니다 |

- 제목줄 빈 곳을 **두 번 누르면** 최대화와 이전 크기가 바뀝니다. 버튼 위에서 두 번 누르면 그 버튼만 두 번 눌립니다.
- 최대화한 채 제목줄을 끌면 Windows 처럼 평소 크기로 돌아와 커서 밑에 붙고, 그대로 옮길 수 있습니다. 누르기만 하거나 두 번 누를 때는 복원되지 않습니다.
- 최대화 중에는 창 가장자리를 끌어 크기를 바꿀 수 없습니다(손잡이가 숨습니다).
- Win+위 화살표도 같은 작업 영역 최대화가 됩니다.
- 최대화한 채 앱을 끄면 다음에 켤 때도 최대화로 열리고, 이전 크기로 누르면 평소 크기로 돌아갑니다.
- 최소화 버튼이 바탕화면 위젯 모드(트레이 끔)에서 숨는 이유: 그 모드에는 작업 표시줄 단추가 없어 최소화하면 되돌릴 길이 없습니다.

> 맨 앞에 띄우기는 예전에 화면 가운데에 크게(1100x800) 띄우고 뒤를 어둡게 했습니다. 크게 보는 일은 최대화가 맡고, 이제는 다른 창 위로 올리기만 합니다. 크기를 바꾸지 않으니 맨 앞에 띄운 채 종료해도 저장되는 창 크기가 꼬이지 않습니다. 최소화했거나 트레이에 숨긴 상태에서 눌러도 창이 함께 나타납니다.

> 예전 이름은 '넓게 보기'였습니다. 창을 넓히는 것보다 **맨 앞으로 가져오는** 것이 핵심이라 이름과 아이콘을 바꿨습니다.

## 트레이와 닫기

| 설정 | 닫기(✕)를 누르면 | 완전히 끄려면 |
|---|---|---|
| 트레이 **사용** | **트레이로 숨깁니다**(종료하지 않고 미리알림도 계속 동작). 트레이 아이콘을 누르면 다시 열립니다 | ☰ 메뉴 또는 트레이 아이콘 메뉴의 **종료** |
| 트레이 **미사용** | 위젯을 **종료**합니다 | 닫기 |

- 트레이를 쓸 때 있던 '_'(트레이로 숨기기) 버튼은 **없앴습니다**. 닫기가 같은 일을 합니다.
- 트레이 아이콘 메뉴에는 최소화, 최대화 항목을 두지 않았습니다(보이기, 숨기기, 설정, 종료).
- 저장되지 않은 변경이 있을 때 종료하려 하면 한 번 묻습니다([서버 연결이 끊겼을 때](서버-연결이-끊겼을-때)).
