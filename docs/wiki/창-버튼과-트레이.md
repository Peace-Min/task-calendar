# 창 버튼과 트레이

위젯 맨 위 제목줄 오른쪽의 버튼과, 트레이를 켰을 때 닫기 동작을 정리했습니다.

> 적용 버전: v0.19.x 이후

## 제목줄 버튼 (왼쪽부터)

| 버튼 | 이름 | 하는 일 |
|---|---|---|
| 겹친 창 아이콘 | **맨 앞에 띄우기** | 위젯을 **다른 창들 위에** 화면 가운데 크게 띄우고 뒤를 어둡게 합니다. 다시 누르거나 **Esc** 로 원래 자리·크기로 돌아갑니다. ☰ 메뉴에도 같은 항목이 있습니다 |
| 핀 | 바탕화면 부착 | 위젯을 바탕화면에 붙이거나 뗍니다 |
| ☰ | 위젯 메뉴 | 맨 앞에 띄우기 · 설정 · **종료** 등 |
| ✕ | 닫기 | 아래 「트레이와 ✕」 참고 |

> 예전 이름은 「넓게 보기」였습니다. 창을 넓히는 것보다 **맨 앞으로 가져오는** 것이 핵심이라 이름과 아이콘을 바꿨습니다.

## 트레이와 ✕

| 설정 | ✕ 를 누르면 | 완전히 끄려면 |
|---|---|---|
| 트레이 **사용** | **트레이로 숨깁니다**(종료하지 않음 · 미리알림 계속 동작). 트레이 아이콘을 누르면 다시 열립니다 | ☰ 메뉴 또는 트레이 아이콘 메뉴의 **「종료」** |
| 트레이 **미사용** | 위젯을 **종료**합니다 | ✕ |

- 트레이를 쓸 때 있던 「_」(트레이로 숨기기) 버튼은 **없앴습니다** — ✕ 가 같은 일을 합니다.
- 저장되지 않은 변경이 있을 때 종료하려 하면 한 번 묻습니다([서버 연결이 끊겼을 때](서버-연결이-끊겼을-때)).
