# 설치기 런타임

설치기는 오프라인 WebView2 x64 런타임 설치 파일을 포함합니다. PC에 런타임이 없으면 앱 실행 전에 설치합니다. 이미 설치되어 있으면 런타임 설치 단계는 건너뜁니다.

## 빌드 담당자

`redist/MicrosoftEdgeWebView2RuntimeInstallerX64.exe`가 필요합니다. 파일이 없으면 빌드를 중단합니다. 저장소에는 큰 바이너리를 커밋하지 않으므로 새 빌드 PC에는 별도로 준비해야 합니다. 폐쇄망에서는 공식 Standalone 설치 파일을 반입합니다.

준비 절차는 저장소의 `redist/README.md`, 빌드 절차는 `installer/README.md`를 참고합니다.

이전 설치기에서 WebView2 미설치 오류가 나면 런타임이 포함된 새 설치기를 사용하거나 공식 오프라인 런타임을 별도로 설치합니다.
