# 설치기 런타임

설치기는 용도에 따라 두 종류입니다.

- 처음 설치용 `TaskCalendarWidget-Setup-v<버전>-full.exe`: 새 PC에 전달합니다. 오프라인 WebView2 x64 런타임을 포함해 파일 하나로 설치합니다. 이미 런타임이 있으면 런타임 설치는 건너뜁니다.
- 공유폴더 업데이트용 `TaskCalendarWidget-Setup-v<버전>.exe`: 기존 사용자의 자동 업데이트가 받습니다. 런타임 파일은 포함하지 않습니다. 런타임이 없는 PC에서는 Full을 안내하고 파일 설치 전에 중단합니다.

.NET 9와 Windows Desktop 런타임(WPF)은 배포용 실행 파일에 자체 포함합니다. 사용자 PC에 .NET SDK나 별도 .NET Desktop Runtime 설치는 필요하지 않습니다. MySQL 연결 라이브러리와 WebView2 로더 DLL도 포함합니다. 사용자 PC에 MySQL 서버를 설치할 필요는 없으며, 사내 DB에 연결할 수 있어야 합니다.

## 빌드 담당자

`배포-빌드.cmd` 한 번으로 두 설치기를 함께 만듭니다. Full에 넣을 `redist/MicrosoftEdgeWebView2RuntimeInstallerX64.exe`가 없으면 전체 빌드를 중단합니다. 저장소에는 큰 바이너리를 커밋하지 않으므로 새 빌드 PC에는 별도로 준비해야 합니다. 폐쇄망에서는 공식 Standalone 설치 파일을 반입합니다.

공유폴더 배포 정보(`latest.json`, 배포 SQL)의 파일명과 해시는 업데이트용 기준입니다. Full은 새 PC용으로 별도 전달하거나 공유폴더에 구분해서 둡니다. `-CopyTo`는 업데이트용과 `latest.json`만 복사합니다.

준비 절차는 저장소의 `redist/README.md`, 빌드 절차는 `installer/README.md`를 참고합니다.

이전 설치기에서 WebView2 미설치 오류가 나면 런타임이 포함된 새 설치기를 사용하거나 공식 오프라인 런타임을 별도로 설치합니다.
