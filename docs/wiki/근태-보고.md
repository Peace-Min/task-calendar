# 근태 보고

상단 **근태** 탭에서 회사 근태관리(일간보고)를 씁니다. 회사 근태관리 화면처럼 날짜를 누르면 입력 창이 열리고, 내용은 한 칸에 씁니다.

> 적용 버전: 다음 판(2026-10-29 개발)

## 근태 탭

- 상단 탭이 **개인 / 과제 / 근태** 셋이 됩니다.
- 달력 칸에는 그날 근태와 보고 글이 보입니다. 근태는 회사 달력과 같은 모양으로 보입니다(예: `야근(+2시간)`, `정근`, `반차`).
- 긴 글은 칸에서 잘립니다. 마우스를 올리면 전체가 보입니다.
- 쓰다가 닫은 날은 `✎ 작성 중`이 보입니다.
- 이 달력은 **이 앱으로 보낸 보고만** 보여 줍니다. 회사 사이트에서 직접 쓴 날은 비어 보입니다.

## 근태 창

날짜를 누르면 **근태 창**이 따로 뜹니다. 관리 창처럼 크기를 끌어 바꾸고 최대화할 수 있고, 마지막 크기와 위치를 기억합니다.

- 이미 보고한 날은 **보기 화면**으로 먼저 열립니다(회사 근태관리의 하루 보기처럼 날짜, 근태, 보낸 시각, 내용). **수정**을 누르면 그 글로 고쳐 쓰고, **닫기**로 닫습니다. 그날 쓰다 만 임시 저장이 있으면 바로 쓰기 화면으로 열립니다.
- 왼쪽: 근태(기본 정근, 미기록은 없습니다), 초과시간, 그 아래 내용 칸.
- 내용 칸 아래: 줄 수, 과제 수와 합계 시간, 임시 저장 시각.
- 위쪽 **‹ ›** 로 전날과 다음날로 넘어갑니다. 쓰던 글은 먼저 임시 저장됩니다.
- 오른쪽 위 **가져오기 패널 접기**로 내용 칸을 넓게 씁니다.

## 가져오기

오른쪽 **가져오기** 패널에서 과제를 골라 내용 칸을 채웁니다. 채운 뒤에는 왼쪽에서 자유롭게 고칩니다.

1. 가져올 곳과 날짜를 고릅니다. 날짜는 아무 날이나 고를 수 있고 처음에는 보고하는 날짜입니다.
   - **캘린더**: 고른 날짜의 개인 캘린더 일정, 할 일, 공수.
   - **근태관리**: 고른 날짜에 회사 근태관리에 이미 등록된 일간보고. 회사 사이트에서 읽기만 하고 아무것도 바꾸지 않습니다. 로그인하느라 몇 초 걸립니다. 어제와 비슷하게 쓰는 날에 편합니다.
2. 캘린더일 때 옵션: 포함 항목(일정, 할 일), 기록 없는 과제 제외, 설명 포함. 옵션은 오른쪽 목록만 바로 바꿉니다.
3. 과제를 체크합니다(전체 선택, 전체 해제도 있습니다).
4. **← 불러오기**를 누르면 왼쪽 내용이 바로 바뀝니다(묻지 않습니다).

- 머리 줄은 보고서와 같은 `[과제명] : 시간` 입니다. 머리기호와 들여쓰기는 보고서 서식 설정을 따릅니다.
- 보고 기록에 남는 과제별 시간은 보낼 때 머리 줄에서 읽습니다. `[과제명] : 5` 와 `[과제명] 5` 모두 읽습니다.

## 임시 저장

- 쓰는 동안 1초마다 **이 PC에** 임시 저장됩니다. 창을 닫거나 앱이 꺼져도, 같은 날짜를 다시 열면 "임시 저장된 글을 이어서 엽니다"와 함께 이어서 씁니다.
- 처음 상태로 돌아가려면 **버리고 처음 상태로**를 누릅니다.
- 회사 보고와 기록 저장이 모두 끝나면 지워집니다. 보내기가 실패하면 남습니다.
- 다른 PC나 브라우저에서는 이어지지 않습니다. 14일 지난 임시 저장은 지워집니다.

## 닫기

- 쓰던 글이 있으면 창 바깥을 눌러도 닫히지 않습니다. 닫기나 창의 X 를 누르면 "작성 중인 내용이 있습니다"를 한 번 묻습니다. 닫아도 임시 저장은 남습니다.

## 회사에 보고

- **회사에 보고**를 누르면 회사 일간보고에 제출하고, 제출이 확인되면 위젯의 보고 기록까지 저장합니다. 둘 다 끝나면 창은 그대로 두고 그날 **보기 화면**으로 바뀌며 달력도 바뀝니다. 고칠 것이 있으면 **수정**을 누릅니다.
- 어느 단계든 실패하면 "처리를 완료하지 못했습니다. 다시 시도해 주세요." 가 뜨고 창과 글이 그대로 남습니다. 다시 누르면 회사 보고부터 다시 합니다(회사 쪽은 같은 날짜를 덮어씁니다).
- 보고서 창의 일간보고 전송과 같은 회사 보고입니다. 어느 쪽으로 보내도 같은 날짜를 덮어씁니다([보고서 회사 전송](보고서-회사-전송)).

## 브라우저에서

- 브라우저에서는 창을 따로 띄우지 않고 근태 탭 안에서 화면이 바뀝니다(**← 근태 달력**으로 돌아옵니다). 보기 화면도 같습니다.
- 가져오기의 **근태관리**는 위젯에서만 됩니다.
- 브라우저는 아직 회사에 자동으로 보내지 못합니다. **복사**해서 회사 사이트에 직접 입력합니다.
