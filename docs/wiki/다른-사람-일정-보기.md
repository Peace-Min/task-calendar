# 다른 사람 일정 보기

상단 툴바의 **👥 다른 사람 일정**에서 사람을 고르면 그 사람의 캘린더가 **따로 뜨는 읽기 전용 창**으로 열립니다. 내 메인 화면에서 보이는 것은 그 사람 것도 그대로 보입니다.

> 적용 버전: v0.19.x 이후

## 여는 법

1. 상단 툴바의 **👥 다른 사람 일정**을 누릅니다(창이 좁으면 아이콘만 보이거나 **⋯** 메뉴 안에 있습니다).
2. 작은 창이 뜨면 '사람' 탭에 ★ 즐겨찾기, 최근 본 사람, **내 부서** 사람들이 바로 보입니다. 다른 부서는 '조직도' 탭(또는 '조직도에서 다른 부서 ›')에서 찾습니다. 이름, 직급, 조직(또는 로그인 ID)을 입력해 검색해도 됩니다.
3. 사람을 누르면(또는 ↓/↑ 로 고르고 **Enter**) "○○ 님의 일정" 창이 따로 열립니다. **Esc** 를 누르면 고르기 창만 닫힙니다.
4. 누구를 볼 수 있는지는 내 **열람 범위**(본인만 / 소속 조직 / 전체)가 정합니다. 범위 밖인 사람은 회색으로 보이고 눌리지 않습니다.

> 예전의 '사용자 정보'에서 '구성원 보기'로 들어가던 입구는 없앴습니다(2026-10-02). 같은 명부를 '조직도' 탭에서 봅니다.

## 열람 창(따로 뜨는 창)

다른 사람 일정은 캘린더 화면 안의 팝업이 아니라 **Windows 창 하나로 따로** 뜹니다(2026-10-16부터).

| | 내용 |
|---|---|
| 창 단추 | 오른쪽 위의 Windows 기본 단추로 최소화, 최대화, 닫기를 합니다. 가장자리를 끌어 크기를 바꾸고, 제목줄을 끌어 다른 모니터로 옮길 수 있습니다 |
| 작업 표시줄 | 캘린더와 따로 작업 표시줄에 뜹니다. 창 제목은 "○○ 님의 일정"이고 사람을 바꾸면 따라 바뀝니다 |
| 창은 하나 | 이미 열려 있을 때 캘린더에서 다른 사람을 고르면 그 창이 앞으로 오고(최소화돼 있으면 되살아나고) 그 사람으로 바뀝니다. 같은 사람을 다시 고르면 보던 달을 그대로 두고 새로 읽어 옵니다 |
| 크기와 위치 기억 | 닫을 때의 크기, 위치, 최대화 여부를 **이 PC 에 하나** 기억해 다음에 그대로 엽니다. 처음에는 캘린더가 있는 모니터 가운데에 1400x900(화면이 작으면 작업 영역의 90%)으로 엽니다. 기억한 자리의 모니터를 뺐으면 주 모니터 가운데로 옮겨 엽니다 |
| 캘린더와의 관계 | 열람 창을 닫아도 캘린더는 그대로입니다. 캘린더를 트레이로 숨겨도 열람 창은 남습니다. 프로그램을 종료하거나 로그아웃하면 열람 창도 닫힙니다 |
| 함께 쓰는 설정 | 즐겨찾기, 최근 본 사람, 테마는 캘린더와 같이 씁니다. 캘린더에서 테마를 바꾸거나 ☆ 를 누르면 열람 창에도 바로 반영됩니다 |

## 사람/조직도 탭

| 탭 | 보이는 것 |
|---|---|
| **사람**(처음 열 때 늘 이 탭) | ★ 즐겨찾기, 최근 본 사람, **내 부서**(나를 뺀 내 조직 사람) 순서로 보입니다. 처음 쓰면 안내 한 줄과 내 부서가 보입니다 |
| **조직도** | 창이 넓으면 왼쪽 조직도 트리와 오른쪽 사람 목록, 두 칸으로 보입니다. 처음엔 **내 부서**가 골라져 있습니다. 조직마다 인원 수가 나오고, 내 조직에는 '내 소속'이 붙습니다. 오른쪽 위 경로("기술개발총괄 › SW개발본부 › SW 3팀")를 눌러 위로 올라가고, 하위 조직 줄을 눌러 내려갑니다. 창이 좁으면 경로를 따라 한 단계씩 내려갑니다 |
| 검색어를 넣으면 | 어느 탭에 있든 검색 결과로 바뀝니다. 탭을 누르면 검색어가 지워지고 그 탭으로 갑니다 |

- 키보드: 탭은 ←/→ 로 옮깁니다. 조직도 트리에서는 ↓/↑ 로 이동하고, → 로 펼치고, ← 로 접고, Enter 로 고릅니다.
- 조직은 모두 펼쳐 볼 수 있고, 내 열람 범위 밖인 사람만 회색입니다.

## 즐겨찾기와 최근 본 사람

| | 내용 |
|---|---|
| ★ 즐겨찾기 | 사람 옆 ☆ 를 누르면 ★ 가 되고, 다시 누르면 해제됩니다. 열람 창 제목 옆 ☆/★ 로도 넣고 뺄 수 있습니다. **최대 20명** |
| 최근 본 사람 | 일정 창이 **실제로 열린** 사람이 맨 앞에 쌓입니다. **최대 5명**이고, 즐겨찾기에 있는 사람은 최근에서 빠집니다 |
| 저장 위치 | 이 PC 에 **내 계정별로** 저장됩니다(다른 PC, 다른 계정과는 따로). 서버에는 저장하지 않습니다 |
| 퇴사 등으로 명부에서 사라진 사람 | 회색으로 "명부에 없음"이 표시되고, ✕ 로 지웁니다 |
| 명부를 못 불러왔을 때 | "명부를 불러오지 못했습니다"와 '다시 시도'가 보입니다. 그래도 즐겨찾기와 최근 본 사람은 눌러서 열 수 있습니다 |

## 열람 창에서 사람 바꾸기

- "○○ 님의 일정" 제목 옆 **▾ 사람 바꾸기**를 누르면 같은 고르기 창이 제목 아래에 뜹니다.
- 고르면 창을 닫지 않고 **그 자리에서** 다른 사람으로 바뀝니다. 보던 달, 보기 방식(겹쳐/나란히), 밀도는 그대로 이어집니다.
- 지금 보고 있는 사람은 '보는 중'으로 표시되고 눌리지 않습니다.

## 보이는 것

| 보이는 것 | 내용 |
|---|---|
| 달력 | 그 사람의 일정, 기간 일정, 반복 일정, 할 일 칩, 과제 필터 |
| 일정 상세 | 시간, **장소, 메모**, 기간("9/29 ~ 10/2 (3일째 / 4일)") |
| 할 일 | 마감, 기간, 완료, 중요, 메모, 날짜별 메모 |
| 커밋 내역 | 그 사람의 작업일지와 커밋 목록 |

## 보이지 않는 것

- 과제별 시간, 근태, 보고서 서식, 미리알림 설정, 저장소 경로는 보이지 않습니다. 보고서 안에서만 쓰는 값이라 보내지 않습니다.
- **고치는 수단은 없습니다**(새 기록, 수정, 삭제, 할 일 체크, 끌어 옮기기). 남의 기록을 바꾸지 않게 하기 위해서입니다.

## 화면 조절

- **밀도**: 창 위쪽 띠에서 '밀도 고정', '촘촘히', '펼침' 중에 고릅니다. 기본은 펼침입니다. 칸이 내용만큼 늘어나 "+N 더보기" 없이 그 사람 일정이 다 보이고, 달력이 창보다 길어지면 달력 안에 세로 스크롤이 생깁니다(겹쳐 보기에서도 칩이 다음 주 칸 밑으로 깔리지 않습니다). 여기서 고른 값은 다른 사람 보기 창에만 기억되고 내 화면 밀도는 그대로입니다.
- **창 크기**: 열람 창의 가장자리를 끌거나 최대화하면 달력도 그만큼 커집니다. 펼침에서 창을 줄이면 스크롤이 생깁니다.
- **보기 방식**: 창 위쪽 띠의 [겹쳐 보기 | 나란히 보기]로 바꿉니다. 아래 두 절을 참고하세요. 고른 방식은 다른 사람 보기 창에만 기억됩니다(기본은 겹쳐 보기).
- **날짜 누르기**: 내 화면과 같습니다. 막대나 칩을 누르면 누른 칸의 날짜가 선택되고 달이 바뀌지 않습니다([날짜 누르기와 기간 일정](날짜-누르기와-기간-일정)).

## 겹쳐 보기 (내 일정 겹쳐 보기)

약속을 잡을 때 빈 시간을 찾기 쉽도록 그 사람 달력 위에 내 일정을 옅게 겹쳐 보여 줍니다. 겹에는 내 **일정만** 나옵니다(할 일과 커밋은 안 나옴).

겹에 나오는 내 일정은 캘린더 창이 지금 가진 내용입니다. 열람 창을 연 뒤에 캘린더에서 일정을 고쳤다면, '내 일정'을 다시 켜거나 나란히 보기로 바꾸거나 열람 창을 다시 앞으로 가져오면 새로 반영됩니다.

| 어디 | 보이는 모습 |
|---|---|
| 창 위쪽 띠(범례) | `[▮▮▮ 이웅빈]`, `[☑ 내 일정]` 칩 두 개가 있습니다. '내 일정' 칩을 누르면 켜고 끕니다(켜지면 칩이 채워짐) |
| 달력 칸 | 그 사람 일정이 먼저 나오고, 옅은 구분선 아래에 **내 일정**(연한 남색 채움과 왼쪽 막대)이 나옵니다. 내 칩에 마우스를 올리면 "내 일정"으로 시작하는 설명이 나옵니다 |
| 일정 상세 | "○○ 님 일정 (N)"과 "내 일정 (M)", 두 묶음으로 나뉩니다 |
| 시간 겹침 | 시간이 정해진 일정끼리 겹치면 상세 카드에 **⏰ 시간 겹침 10:00~11:30**(겹치는 일정이 더 있으면 "외 1"처럼 붙습니다) 이 붙고, 달력 칸 날짜 옆에 작은 주황 점이 찍힙니다 |

- 시간 겹침은 시작 시간이 있는 하루짜리 일정만 셉니다(종일 일정과 기간 일정 제외). 한쪽이 끝나는 시각에 다른 쪽이 시작하면 겹침이 아닙니다. 끝 시간이 없으면 30분으로 봅니다.
- 상용 캘린더(Google, Outlook, Apple)처럼 색과 이름으로 누구 것인지 나눕니다. 예전의 "점선 = 내 일정" 표시는 없앴습니다.
- 라이트, 다크, 포레스트, 세피아, 고대비 모든 테마에서 글자 대비가 AA(4.5:1) 이상입니다.

## 나란히 보기

Outlook 처럼 **그 사람 달력과 내 달력을 좌우로 동시에** 띄웁니다. 그 사람 달력을 섞지 않은 채 보면서 내 달과 큰 흐름(바쁜 주, 휴가 기간)을 비교할 때 씁니다.

| 어디 | 보이는 모습 |
|---|---|
| 왼쪽 달력 | "▮▮▮ ○○ 님" 탭. 그 사람의 일정, 기간 일정, 할 일이 나옵니다. 과제 필터는 이쪽에만 걸립니다 |
| 오른쪽 달력 | "▮ 내 일정" 탭. 내 일정만 나옵니다(할 일과 커밋은 안 나옴) |
| 줄 맞춤 | 두 달력의 **같은 주는 같은 높이**라서 좌우로 같은 날을 바로 비교할 수 있습니다. 펼침과 촘촘히에서는 세로 스크롤도 같이 움직입니다 |
| 날짜 누르기 | 어느 쪽 칸을 눌러도 같은 날짜가 양쪽에 선택되고, **아래에서 일정 상세가 올라옵니다**("○○ 님 일정"과 "내 일정" 두 묶음, 시간 겹침 표시). 위쪽 손잡이로 닫습니다 |
| 달 이동 | ‹ ›, 오늘을 누르면 두 달력이 함께 넘어갑니다 |
| 좁은 창 | 창이 좁으면 위(그 사람)와 아래(나)로 쌓습니다 |

- 나란히 보기에서는 오른쪽이 곧 내 일정이라 '내 일정' 켜고 끄기 칩이 숨겨집니다. 겹쳐 보기로 돌아가면 예전 켜짐/꺼짐 상태 그대로입니다.
- 시간이 겹치는 날은 **두 달력 모두** 날짜 옆에 주황 점이 찍힙니다.
- **어느 걸 쓰나**: 약속을 잡을 때(같은 날 둘 다 비었는지)는 겹쳐 보기, 그 사람의 한 달 흐름을 볼 때는 나란히 보기가 맞습니다.

## 고쳐진 것 (2026-10-01)

- 할 일, 커밋 내역 탭과 일정의 장소, 메모가 보이지 않던 것을 고쳐 이제 보입니다.
- 작은 창에서 "+N 더보기" 때문에 일정이 가려지던 것은 기본 펼침과 큰 창으로 바꿨습니다.
- 창을 열 때마다 아무것도 안 눌렀는데 "읽기 전용 보기입니다"가 잠깐 뜨던 것은 이제 무언가를 고치려 할 때만 뜹니다.
- '내 일정 겹쳐 보기'가 점선 상자로 조잡하게 보이고 남의 일정과 내 일정이 섞이던 것은 위처럼 다시 그렸습니다. 겹을 켰는데 체크가 꺼진 채 보이던 불일치도 고쳤습니다.
- (2026-10-02) '나란히 보기' 모드를 더했습니다. 펼침 밀도에서 창 크기를 바꾸면 마지막 일정이 "+1개 더보기"로 접히던 것도 고쳤습니다.
- (2026-10-02) 다른 사람 일정을 보려면 '사용자 정보', '구성원 보기', '조직도'를 차례로 거쳐야 해서 숨은 기능처럼 느껴졌습니다. 이제 툴바의 '👥 다른 사람 일정' 한 번으로 열리고, 즐겨찾기와 최근 본 사람, 창 안에서 사람 바꾸기가 생겼습니다.
- (2026-10-02) 고르기 창을 열면 검색 칸만 있어 막연했습니다. 이제 '사람' 탭에 내 부서가 기본으로 보이고, '조직도' 탭이 생겼습니다(네이버웍스 '구성원 일정 보기' 방식).
- (2026-10-16) 겹쳐 보기와 내 달력의 '펼침'에서 칸이 내용만큼 늘지 않아 칩이 다음 주 칸 밑으로 깔리고 스크롤도 생기지 않던 것을 고쳤습니다.
- (2026-10-16) 열람 창의 크기가 캘린더 창 안에서 고정이라 자유롭게 키울 수 없었습니다. 이제 따로 뜨는 Windows 창이라 크기와 위치를 마음대로 바꾸고, 최대화하고, 다른 모니터로 옮길 수 있고, 마지막 크기와 위치를 기억합니다.
