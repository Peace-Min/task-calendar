# 사용 영상

앱 안에서 기능별 사용 영상을 봅니다. 영상은 설치 파일(Setup)에 들어 있지 않고, 운영자가 업데이트 폴더에 따로 올립니다. 규칙의 정본은 [`docs/GUIDE-VIDEOS.md`](https://github.com/Peace-Min/task-calendar/blob/feat/db-app/docs/GUIDE-VIDEOS.md) 입니다.

## 사용자

- **언제든 보기**: 위쪽 **?** 도움말 창 아래의 **[사용 영상]** 을 누릅니다. 왼쪽 목록에서 영상을 고르고, 영상 아래 장면 단추를 누르면 그 장면부터 재생합니다. 자막이 있으면 영상의 자막 메뉴에서 켜고 끕니다.
- **켤 때 한 번 묻기**: 로그인하고 첫 화면이 뜬 뒤 한 번 묻습니다. 처음 쓰는 계정(일정과 할 일이 하나도 없음)은 "사용 영상을 보시겠습니까?", 그 밖은 "새 기능 가이드가 추가되었습니다" 입니다.
  - **[보기]**: 영상 창을 열고, 이 판은 본 것으로 기억합니다.
  - **[다시 묻지 않기]**: 영상은 열지 않고 이 판은 본 것으로 기억합니다.
  - **[나중에]**(× 와 Esc 도 같음): 기억하지 않습니다. 다음에 앱을 켤 때 다시 묻습니다.
- 기억은 이 PC 에 계정별로 남습니다. PC 를 바꾸면 한 번 더 물을 수 있습니다. 같은 실행 안에서는 두 번 묻지 않고, 다른 계정으로 로그인하면 그 계정 기준으로 다시 판단합니다.
- 공유 폴더에 닿지 않거나 영상이 아직 없으면 묻지 않습니다. 영상 창에는 짧은 안내만 뜹니다.

## 운영자: 무엇을 올리나

업데이트 폴더(`latest.json` 과 Setup 이 있는 곳) 아래 `guide` 폴더에 세 가지를 올립니다.

```
<업데이트 폴더>\guide\
  guide.json      판 번호와 영상 목록
  *.mp4           기능별 영상
  *.srt           (선택) 영상과 같은 이름의 자막
```

`guide.json` 예:

```json
{
  "version": "2026-11",
  "videos": [
    { "id": "overview", "file": "overview.mp4", "title": "전체 소개" },
    { "id": "report", "file": "report.mp4", "title": "보고서",
      "chapters": [ { "t": 0, "title": "일간" }, { "t": 80, "title": "주간" } ] }
  ]
}
```

- `id` 는 영상마다 다르게, `file` 은 `guide` 폴더 안의 mp4 이름(폴더 경로, `..` 없이), `title` 은 목록에 보일 이름입니다.
- `chapters` 는 선택입니다. `t` 는 장면이 시작하는 초입니다.
- 자막은 mp4 와 같은 이름에 확장자만 `.srt` 로 둡니다(`report.mp4` 와 `report.srt`).
- 규칙에 맞지 않는 줄은 앱이 건너뜁니다. 쓸 영상이 하나도 없으면 묻지 않습니다.

## 운영자: 판 번호 올리기

- **모두에게 다시 알리고 싶을 때**(새 기능 영상을 올림): `version` 값을 바꿉니다. 날짜든 숫자든 이전과 다르기만 하면 됩니다. 모든 계정이 다음 실행 때 한 번 받습니다.
- **조용히 고칠 때**(영상 교체, 오타 수정, 영상 추가): `version` 은 그대로 두고 파일과 목록만 고칩니다. 아무에게도 다시 묻지 않고, "?" 의 [사용 영상] 에는 바로 보입니다.
- 앱 릴리스 산출물(`latest.json`, Setup, `release-v<버전>.sql`)은 그대로입니다. 영상과 `guide.json` 은 릴리스와 따로 올립니다. 화면을 바꾼 릴리스라면 영상을 다시 찍을지, 판 번호를 올릴지 정합니다.

## 업데이트 폴더 형식별 동작

| 업데이트 폴더 | 재생 |
|---|---|
| 로컬 경로, UNC(`\\서버\공유`), `file://` | 처음 볼 때 그 영상을 이 PC 로 복사한 뒤 재생합니다(복사 중 % 표시) |
| `ftp://`, `http(s)://` | 처음 볼 때 그 영상만 이 PC 로 받은 뒤 재생합니다(받는 중 % 표시) |

- 한 번 복사하거나 받은 영상은 같은 판 번호 동안 다시 받지 않습니다(크기가 바뀌었으면 다시 받습니다). 판 번호가 바뀌면 지난 판의 영상은 지웁니다.
