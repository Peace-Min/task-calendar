# 캘린더를 활용한 근태 작성 시안

2026-10-27 사용자 피드백을 반영한 비교 시안이다. 작성 UI는 검토 중이며 제품 반영 완료가 아니다.

사용자는 캘린더의 데이터를 다시 타이핑해야 하는 근태 화면은 의미가 없고, 날짜를 누르면 바로 편집해야 하며, 여러 과제를 긴 폼으로 작성하는 방식이 불편하다고 지적했다. 이에 캘린더 항목을 블록으로 추가하거나 초안으로 활용하는 세 방식을 비교한다.

- A: 원본 항목을 골라 보고서에 조립.
- B: 과제를 전환하며 해당 과제에 집중해 편집.
- C: 캘린더로 채운 초안을 표에서 검토하고 제외.

[시안 실행 및 조작 안내](../prototypes/attendance-composer/README.md), [최신 인계 문서](../handoff/2026-10-27-attendance-composer.md)를 참고한다. 파일로 직접 열 수 있어 폐쇄망에서도 가상 데이터로 비교할 수 있다.

회사 전송 및 DB 저장의 확정 규칙은 [근태 보고 처리 정책](근태-보고-처리-정책)을 따른다. 블록은 편집 도구이며 새 DB 테이블 추가는 결정하지 않았다.
