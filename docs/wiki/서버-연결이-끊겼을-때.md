# 서버 연결이 끊겼을 때

캘린더의 모든 기록은 **회사 서버 DB**에 저장됩니다. 서버에 연결할 수 없으면 위젯은 기록을 **읽기 전용**으로 두고, 연결이 돌아오면 스스로 다시 붙습니다. 이 PC에 따로 몰래 저장해 두지 않습니다.

> 적용 버전: v0.19.x 이후

## 이런 화면이 보이면

### 「서버에 연결할 수 없습니다 — 서버가 꺼져 있거나 네트워크 문제입니다」

제목줄 아래 빨간 상자로 뜹니다.

- **하실 일은 없습니다.** 위젯이 15초 · 30초 · 60초 뒤에 다시 시도하고, 그 뒤로는 **5분마다** 계속 시도합니다. 연결되면 상자가 사라지고 「서버에 다시 연결되었습니다」가 한 번 뜹니다.
- 바로 확인하고 싶으면 상자의 **[다시 시도]** 를 누르세요.
- 그동안 새 기록·수정·삭제는 막힙니다(「서버에 연결되지 않아 지금은 편집할 수 없습니다」). 이미 보이던 기록은 그대로 볼 수 있습니다.
- 그날 미리알림은 연결이 돌아온 뒤부터 다시 울립니다.

### 「저장되지 않은 변경이 있습니다 — 서버 연결이 끊겼습니다 · 다시 연결되면 자동으로 저장합니다」

쓰던 중에 서버가 끊겨 **방금 한 변경이 아직 서버에 가지 않았다**는 뜻입니다.

- 변경은 화면에 남아 있고, 연결이 돌아오면 **자동으로 저장**됩니다. **[지금 다시 시도]** 로 바로 시도할 수도 있습니다.
- 이 상태에서는 다른 편집이 잠깁니다(변경이 쌓이면 꼬일 수 있어서입니다).
- **위젯을 닫지 마세요.** 닫으려 하면 「저장되지 않은 변경이 있습니다. 지금 닫으면 이 변경은 사라집니다.」 확인 창이 뜹니다. 「아니오」를 누르면 닫히지 않습니다.

### 「DB 접근이 거부되었습니다」

서버는 켜져 있지만 **위젯의 접속 설정이나 서버 권한**이 맞지 않는 경우입니다. 기다려도 저절로 풀리지 않으므로 위젯은 다시 시도하지 않습니다.

- 상자에 보이는 `DB이름@서버` 를 **관리자에게 알려 주세요.** [자세히] 를 누르면 원인 문구가 보입니다.

### 「DB 구조가 이 버전과 맞지 않습니다」 · 「서버 DB 업데이트 필요」 · 「위젯 업데이트 필요」

서버와 위젯의 버전이 어긋난 경우입니다.

- 「위젯 업데이트 필요」 → 위젯을 최신 버전으로 업데이트하세요(상단 업데이트 배너).
- 「서버 DB 업데이트 필요(관리자)」 → 관리자에게 알려 주세요.

### 「보고는 전송됐지만 기록 저장에 실패했습니다」

일간·주간 보고는 **회사 사이트에 정상 전송**됐고, 위젯 안의 「보고 기록」 한 줄만 남지 못한 경우입니다. 보고를 다시 보낼 필요는 없습니다.

## 자주 묻는 것

- **연결이 끊긴 동안 쓴 내용은 어디에 있나요?** 「저장되지 않은 변경」 막대가 떠 있는 동안 화면(메모리)에만 있습니다. 연결되면 서버로 갑니다. 위젯을 닫으면 사라집니다.
- **PC를 켰더니 바로 연결 오류가 떠요.** 서버(DB)가 위젯보다 늦게 켜진 경우가 많습니다. 몇십 초에서 몇 분 안에 저절로 풀립니다.
- **로그인 화면에서 「DB에 연결하지 못했습니다」가 떠요.** 서버가 꺼져 있거나 네트워크 문제입니다. 잠시 뒤 다시 로그인하세요. 로그인에 성공하면 캘린더가 바로 다시 읽힙니다.
