# 장소 입력과 회의실

일정의 **장소** 칸은 회사 공용 회의실 목록에서 고르거나, 아무 장소나 직접 적는 칸입니다.

> 적용: 2026-10-21 회의실 공용화 이후 버전

## 고르기

- 일정 입력 창이나 빠른 추가(장소, 반복, 기간, 메모 ▾)의 **장소** 칸을 누르면 회의실 목록이 펼쳐집니다. 칸 오른쪽 ▾ 를 눌러도 됩니다.
- 글자를 치면 그 글자가 든 회의실만 남고, 맞는 부분이 강조됩니다.
- 키보드: **↓ / ↑** 로 고르고 **Enter** 로 넣습니다. **Esc** 는 목록만 닫습니다(창은 그대로). Tab 은 목록을 닫고 다음 칸으로 갑니다.
- 칸 오른쪽 **×** 는 장소를 지웁니다.

## 직접 입력

- 목록에 없는 장소(예: 고객사 3층 회의실, 화상회의)는 칸에 **적은 그대로** 저장됩니다. 목록이 비어 있어도 됩니다.
- 예전 일정에 적힌 장소도 그대로 열리고 그대로 보입니다. 예전의 '(미등록)' 표시는 없어졌습니다.

## 회의실 목록은 누가 고치나

- 목록은 회사 공용 하나이고 **관리자**가 [관리 화면](관리-화면)의 **🗓 일정 › 🚪 회의실**에서 고칩니다.
- 일반 사용자 화면에는 '회의실 관리'가 없습니다(예전의 ⋯ 메뉴, 일정 입력 창, 빠른 추가의 '회의실 관리'는 없어졌습니다). 목록에 넣고 싶은 회의실이 있으면 관리자에게 알려 주세요.
- 관리자가 이름을 바꾸거나 지워도 이미 저장된 일정의 장소 글자는 바뀌지 않습니다.
