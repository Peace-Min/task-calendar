# 근태 보고 프리셋 (자주 쓰는 글 Ctrl+1~9)

상태: 구현(2026-11-09), 시안 `dist/proto/report-preset-v2.html#B-open`(채택 B안). 다음 판. 시험 `tests/report-preset.test.mjs`.

> 보고 본문에 매번 똑같이 쓰는 머리 글(담당자 목록, 과제 머리 줄 등)을 사용자마다 한 곳에 저장해 두고, 본문 칸에서 Ctrl+1~9 로 바로 넣는다.

## 배경

- 일부 사용자는 일간, 주간 보고 본문 앞에 같은 글을 날마다 다시 친다. 예(가짜 이름):

  ```
  ***********************************************
  > 시스템운용 : 홍길동/김철수/이영희
  > 교관훈련통제 : 홍길동/박민수
  ***********************************************
  [가상 훈련장비](~'28/12)
  ```

- 과제마다 다른 글이지만, 사용자는 과제별로 묶어 관리하기보다 **저장소 하나에 칸을 두고 단축키로 꺼내 쓰기**를 원한다(2026-11-09 사용자).

## 결정 (2026-11-09 사용자)

1. **저장소는 사용자마다 하나, 칸 9개.** 칸 = 이름(선택, 목록에서 알아보기용) + 글(여러 줄). 과제와 묶지 않는다.
2. **키는 Ctrl+1~9.** Shift+숫자는 `! @ # * (` 같은 글자를 못 치게 되고(예시의 `*` 도 Shift+8), Alt+0~7 은 본문 수준 키라 쓰지 않는다. 숫자 줄 키만(숫자 패드 무시).
3. **저장은 이 PC 의 계정별 localStorage.** 문단 모양(`tc_attOutline:<계정>`), 보고 글꼴(`tc_rptFont:<계정>`)과 같은 층. DB 는 나중에(아래 "저장소").

## 동작

- **넣는 곳**: 작성 보조 도구가 붙는 모든 본문 칸(일간 과제 블록 글, 자유 메모, 주간 표의 글 칸). 커서 자리에 넣고, 고른 글이 있으면 바꾼다.
- **되돌리기**: 넣기는 `waEdit`(insertText) 로 해서 Ctrl+Z 한 번에 빠진다.
- **빈 칸**: 아무것도 넣지 않고 바닥 줄 메시지에 "3번 프리셋이 비어 있습니다." 한 줄(토스트, 확인 창 없음).
- **한글 조합 중**: 수준 키와 같이 조합이 끝난 뒤 한 번 넣는다(`waLater`).
- **글은 그대로 넣는다.** 문단 모양(머리기호, 들여쓰기)으로 다시 그리지 않는다. 저장한 그대로가 사용자가 원하는 모양이다.
- 위젯 호스트는 `AreBrowserAcceleratorKeysEnabled = false` 라 Ctrl+숫자가 페이지까지 온다(확인함).

## 관리 화면

- 머리 줄 작성 보조 도구에 **[프리셋]** 단추 하나를 [문단 모양] 옆에 둔다.
- **자리는 문단 모양과 같은 급**(2026-11-09 사용자). 프리셋은 이 보고의 내용을 보고 가져오는 오른쪽 패널([미리보기][가져오기])이 아니라, 문단 모양처럼 사람마다 한 번 정해 두고 쓰는 작성 도구 설정이다. 넣기는 Ctrl+숫자가 주 경로라 창은 주로 고칠 때만 연다.
- 누르면 **문단 모양 창(#waPop)과 같은 틀의 큰 띄움 창**(폭 약 760px)이 열린다(새 창을 따로 그리지 않고 #waPop 을 모드로 쓴다. 근태 창 allowlist 문제도 피한다). 시안 v2 의 B안.
  - 왼쪽: 9칸 목록(`Ctrl+1` 과 이름, 이름이 없으면 글 첫 줄, 빈 칸은 "비어 있음").
  - 오른쪽: 고른 칸 하나의 이름 칸과 글 칸(남는 높이 전부), 바닥 [넣기].
  - [넣기] = 마지막에 쓰던 본문 칸에 그 글을 넣는다(마우스로 쓰는 사람과, 단축키를 모르는 사람을 위한 길).
  - 첫 시안(v1, 9칸을 한 창에 모두 펼침)은 답답해서 버렸다. 오른쪽 패널 탭안(v2 A안)은 위 이유로 버렸다.
  - 고치면 바로 저장(저장 단추 없음). 창의 글 칸은 보통 입력 칸이라 Ctrl+Z 도 그 칸의 되돌리기다(문단 모양 창의 표 되돌리기는 문단 모양일 때만).
  - 이름만 있고 글이 빈 칸은 빈 칸이다(목록에 이름이 흐리게, 넣으면 빈 칸 메시지).
- 설명 문구는 두지 않는다. 단추 title 에만 "자주 쓰는 글(Ctrl+1~9)".

## 저장소: 지금 localStorage, 나중에 DB

- 키 `tc_attPreset:<계정>`, 값 `{ v: 1, slots: [{ name, text }] }`(9칸). 계정 규칙은 문단 모양과 같다(`waWho`).
- **지금 localStorage 로 하는 이유**
  - DB 구조를 바꾸지 않아 다음 배포가 Setup 만으로 끝난다(이관 SQL, 구조 번호 관문 없음).
  - 같은 성격의 개인 설정(문단 모양, 글꼴)이 이미 이 층에 있다. 구조 22 에서 쓰지 않던 `cal_user_pref` 를 지웠다.
- **위험**: PC 를 바꾸거나 위젯 데이터(WebView2 사용자 폴더)를 지우면 사라진다. 업데이트(Setup 덮어쓰기)로는 지워지지 않는다.
- **나중에 DB 로 옮길 때**: 프리셋 하나만 옮기지 말고 문단 모양, 글꼴과 **함께** 사용자 설정 표 하나(`user_id`, 키, JSON 값)로 옮긴다. 첫 실행 때 localStorage 값을 DB 로 한 번 올리고, 이후 DB 가 원본. 이 판에서는 하지 않는다.

## 시험(개발 때)

- 단위: 칸 읽기 쓰기(깨진 값, 옛 값, 9칸 아닌 값), Ctrl+1~9 판정(숫자 패드, Shift, Alt 와 함께 누름은 무시), 빈 칸 메시지.
- 정적: [프리셋] 단추가 일간, 주간 머리 줄 모두에 있는지, 근태 창 allowlist 에 걸리지 않는지(#waPop 재사용).
- 변이: 키를 Shift+숫자로 바꾸거나, 문단 모양으로 다시 그리거나, 넣기를 value 대입으로 바꾸면(되돌리기 깨짐) 잡는다.
