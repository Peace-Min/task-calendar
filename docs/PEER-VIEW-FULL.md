# 타인 일정 보기 개선 — 기획서

> 2026-10-01 · 대상 v0.19.x · 파이프라인 **기획 → 개발 → QA → 위키** 의 1단계 산출물. 개발·QA 의 정본.

## 0. 요구(사용자 2026-10-01)

1. 날짜를 누르면 이상하게 달이 바뀌는 문제가 **타인 일정 보기에서도** 나는지 확인.
2. 타인 일정을 볼 때 「일정 상세」만이 아니라 **캘린더 메인 화면에서 보이는 것은 다 볼 수 있게**.
3. 타인 일정 보기에서 「+N 더보기」 때문에 **그 사람 일정이 잘 안 보인다**.

## 1. 현재 동작(조사)

| 항목 | 지금 | 근거 |
|---|---|---|
| 열람 창 | 「구성원 보기」에서 사람을 누르면 `#peerModal`(폭 ≤1180px · 높이 ≤96vh) 안의 **iframe 에 같은 앱을 PEER 모드로** 띄운다 | `openPeerSchedule` · `mountPeerFrame` |
| 날짜 클릭 | iframe 도 같은 그리드 클릭 처리를 쓴다 → 기간 칩 클릭 수정(`ee83d77`)이 **그대로 적용**되어야 한다(실측 필요) | grid click handler |
| 받는 데이터 | 호스트 `LoadPeerScheduleJsonAsync` 가 **과제(이름·색)와 일정만** 보낸다(「최소 payload」 원칙). 일정도 일부 필드만 | `CalendarDb.cs` |
| 숨기는 화면 | `#dptab-todo`(할 일) · `#dptab-git`(커밋 내역) 탭을 감춘다 — 안 보내는 데이터라 비어 보이는 거짓을 막으려고 | `body[data-peer]` CSS |
| 밀도 | 내 화면과 같은 「월 보기 밀도」(기본 **고정 · +N 더보기**)를 쓴다 — 모달 안이라 칸이 작아 금방 넘친다 | `calDensity()` |
| 권한 | 누구를 볼 수 있는지는 `view_scope`(self / unit_tree / all)가 정한다 — 이 기획에서 바꾸지 않는다 | `peerSchedule` |

## 2. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| P1 | 날짜 클릭(요구 1) | 열람 창에서도 칩·칸을 누르면 **누른 칸의 날짜**가 선택되고 달이 멋대로 바뀌지 않는다(내 화면과 같다) |
| P2 | 보이는 범위(요구 2) | **내 메인 화면에서 보이는 것은 열람 창에서도 보인다**: 일정(시간·장소·메모·반복 포함), **할 일**(마감·기간·완료·중요·메모·날짜별 메모), **커밋 내역**(작업일지 일정과 커밋 목록). 「할 일」·「커밋 내역」 탭을 연다. 그리드의 할 일 칩·🔧 작업일지 칩도 내 화면과 같은 규칙으로 그린다 |
| P3 | 보이지 않는 것(유지) | 내 화면에서도 보고서 안에서만 쓰는 값 — **과제별 시간·근태·보고서 서식·회의실 목록·알림 설정·저장소 경로** — 은 보내지 않는다. 편집 수단(새 기록·수정·삭제·체크·끌기)은 지금처럼 없다(읽기 전용) |
| P4 | 밀도(요구 3) | 열람 창은 기본 **「펼침」**(칸이 내용만큼 늘어나고 스크롤) — 「+N」 없이 그 사람 일정이 다 보인다. 열람 띠에 **밀도 전환**(고정 / 촘촘히 / 펼침)을 두고, 고른 값은 **열람 창 전용**으로 기억한다(내 화면 밀도와 분리) |
| P5 | 창 크기 | 열람 모달을 위젯 창에 맞게 **가능한 한 크게**(가로·세로 여백 최소) — 칸이 커져야 고정 밀도에서도 덜 넘친다 |
| P6 | 내 일정 겹쳐 보기 | 기존 「내 일정 겹쳐 보기」 토글·모양은 그대로(내 겹은 지금처럼 일정만) |
| P7 | 권한 | 누구를 볼 수 있는지는 그대로(`view_scope`). 볼 수 있는 사람에 대해 **보이는 항목이 늘어날 뿐**이다 |

## 3. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| Q1 | 열람 창 10월 달력에서 9/29~10/2 기간 막대의 10/1 칸 클릭 → 10월 유지 · 선택 10/1 | 실 위젯 |
| Q2 | 열람 창에 「할 일」·「커밋 내역」 탭이 보이고, 그 사람의 할 일·커밋이 내 화면과 같은 규칙으로 나온다 | 계약 + 실 위젯(loop-peer-view 갱신) |
| Q3 | 열람 창 일정 카드에 시간·장소·메모가 보인다 | 실 위젯 |
| Q4 | 페이로드에 과제별 시간·근태·서식·회의실·알림·저장소 경로가 **없다** | 계약(호스트 SELECT 목록) + 실 위젯 |
| Q5 | 열람 창 기본 밀도 = 펼침 · 「+N」 없음 · 전환이 열람 창에만 기억된다(내 화면 밀도 불변) | jsdom + 실 위젯 |
| Q6 | 열람 창에 편집 수단이 여전히 없다(새 기록·수정·삭제·할 일 체크·끌기) | 기존 loop-peer-frame 갱신 |
| Q7 | 권한 없는 사람은 여전히 못 본다 | 기존 시험 |
| Q8 | 기존 스위트·루프 무회귀 | strict · run-loops |

## 4. 범위 밖

- 다른 사람의 과제별 시간·근태 열람(보고서 영역) — 필요하면 따로.
- 열람 창에서 그 사람의 보고서 미리보기.
