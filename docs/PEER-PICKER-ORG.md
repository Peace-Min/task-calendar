# 사람 고르기 — 「내 부서」 기본 표시 · 「조직도」 탭 — 기획서

> 2026-10-02 · 대상 v0.19.x · 파이프라인 **기획 → 개발 → QA → 위키** 의 1단계 산출물. 개발·QA 의 정본.
> 앞 단계: [`PEER-PICKER.md`](PEER-PICKER.md)(툴바 입구 · 검색 · 즐겨찾기 · 최근 · 사람 바꾸기 — 구현 완료). 이 문서는 그 위에 얹는다(K1–K12 는 그대로 유효).
> 프로토타입: `dist/rehearsal/picker-proto/index.html` 의 **A안**(2026-10-02 사용자 선택).

## 0. 요구

사용자: 「다른 사람 일정」을 눌렀을 때 조직도가 안 나와서 **막연하다** — 다른 캘린더 UI/UX 참고. 프로토타입 A/B 중 **A안(탭 [사람 | 조직도])** 으로 결정.

## 1. 참고

| 제품 | 첫 화면 |
|---|---|
| 네이버웍스 「구성원 일정 보기」 | **내 부서**가 기본 · 다른 부서는 검색 또는 **조직도** · 즐겨찾는 일정 |
| Outlook 「주소록에서 추가」 | 전체 주소 목록이 처음부터 펼쳐짐 + 검색 |
| Google 「사용자 검색」 | 검색 칸만(대신 본 사람이 사이드바에 남음) |

## 2. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| G1 | 탭 | 검색 칸 아래 **[사람 \| 조직도]** 탭(`role="tablist"` · 각 탭 `role="tab"` + `aria-selected`). 팝오버를 열 때마다 **「사람」** 으로 시작한다(예측 가능 · 저장 안 함). 검색어가 있으면 탭은 흐려지고(눌러도 됨 — 누르면 검색어를 지우고 그 탭으로) 본문은 검색 결과(K3 그대로) |
| G2 | 「사람」 탭 | 위에서부터 **★ 즐겨찾기 → 최근 본 사람 → 내 부서**. 내 부서 = 회신의 `myUnit` 에 **직속**한 사람(나 제외 · 즐겨찾기/최근에 이미 나온 사람 제외 — 같은 사람 두 줄 금지). 머리말 「내 부서 · <조직명> N명」(N = 나를 뺀 그 조직 직속 인원) + 오른쪽 링크 **「조직도에서 다른 부서 ›」**(누르면 조직도 탭 · 내 부서 선택) |
| G3 | 처음 쓰는 사람 | 즐겨찾기·최근이 둘 다 비면 맨 위에 안내 한 줄 「☆ 를 누르면 즐겨찾기에 남고, 한 번 본 사람은 「최근 본 사람」에 쌓입니다.」 — 그 아래 내 부서가 바로 보인다(빈 화면 금지) |
| G4 | 「조직도」 탭 — 넓을 때 | 팝오버가 **넓어져**(약 660px · 화면 안으로 당김) **왼쪽 트리 \| 오른쪽 목록** 두 칸. 트리: 「구성원 보기」와 같은 조직 순서(`mbCmp` = sortOrder → 이름) · 하위가 있으면 ▸/▾ 펼침 · 조직마다 **인원 수**(그 조직과 하위 전체 · 나 제외) · 내 조직에 「내 소속」 꼬리표. **처음 선택 = 내 부서**, 펼침 = 루트와 내 부서까지의 경로 |
| G5 | 오른쪽 목록 | 맨 위 **경로**(「회사 › 본부 › 팀」, 조상은 눌러서 이동) · 그 아래 **하위 조직 줄**(이름 · N명 · ›, 누르면 그 조직으로) · 구분선 · 그 조직 **직속 사람** 행(K4 행과 같은 모양: 이름·직급·조직 · ☆/★ · 범위 밖 회색). 상위 조직을 골라도 비지 않는다(하위 조직 줄이 있다). 사람도 하위도 없으면 「이 조직에는 사람이 없습니다」 |
| G6 | 「조직도」 탭 — 좁을 때 | 두 칸이 들어갈 폭이 없으면(팝오버가 넓어질 수 없을 때 · 기준은 개발이 정함, 대략 < 640px) **한 칸**: 경로 + 하위 조직 줄 + 직속 사람 — **한 단계씩 내려가기**(G5 와 같은 목록) |
| G7 | 열람 창 「▾ 사람 바꾸기」 | 같은 팝오버라 탭·내 부서·조직도가 똑같이 있다. 넓어질 때도 열람 창 머리 폭 안으로 맞춘다. 「보는 중」 규칙(K9) 그대로 — 조직도 목록에서도 회색 |
| G8 | 키보드 | 탭: ←/→ 로 탭 이동(활성화) · 트리: ↓/↑ 이동 · → 펼치기(펼쳐져 있으면 첫 하위로) · ← 접기(접혀 있으면 부모로) · Enter/Space 선택. 검색 칸 ↓ 는 지금 보이는 본문의 첫 행으로(K11). Esc 는 팝오버만 닫기(K11 그대로) |
| G9 | 데이터 | 지금의 `membersGet {includeInactive:false}` 회신의 `units` · `members` · `myUnit` 만 쓴다(새 호스트 명령 없음 · 열 때마다 새로 읽음). `myUnit` 이 없거나 트리에 없으면: 「사람」 탭에서 내 부서 묶음을 빼고, 조직도 탭은 첫 루트를 선택. 명부 실패면 조직도 탭에 「명부를 불러오지 못했습니다 · 다시 시도」(K3 와 같은 문구·버튼) |
| G10 | 지키는 것 | K1–K12 전부(최근은 열람 성공 시만 · 즐겨찾기 20 · 최근 5 · 계정별 키 · 범위 밖 회색은 안내일 뿐 판정은 호스트 · 봉인 불변) · 조직은 **모두 눌러서 볼 수 있다**(범위는 사람 행의 회색으로만) · DB 문자열은 textContent · 테마 토큰만(5종 대비 AA) · 「구성원 보기」 모달은 그대로 |

## 3. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| R1 | 탭 마크업·aria · 열 때 늘 「사람」 · 검색어 → 결과 · 탭 누르면 검색어 지움 | jsdom |
| R2 | 「사람」: 즐겨찾기 → 최근 → 내 부서 순서 · 내 부서에서 나/중복 제외 · N명 · 링크 → 조직도 탭 + 내 부서 선택 | jsdom |
| R3 | 처음 쓰는 사람: 안내 한 줄 + 내 부서 | jsdom |
| R4 | 조직도(넓음): 두 칸 · 트리 순서 = 구성원 보기 · 인원 수(하위 포함 · 나 제외) · 「내 소속」 · 처음 선택 = 내 부서 · 경로 펼침 | jsdom + 실 위젯 |
| R5 | 오른쪽 목록: 경로(조상 클릭 이동) · 하위 조직 줄 · 직속 사람 · 범위 밖 회색 · 빈 조직 문구 | jsdom |

| R8 | 키보드(탭 ←/→ · 트리 ↓/↑/→/← · Enter) | jsdom |
| R9 | myUnit 없음/트리에 없음 · 명부 실패 | jsdom |
| R10 | 실 DB: 툴바 → 조직도 탭 → 대상의 조직 선택 → 대상 행 → 열람 · 봉인 · DB 무변화 · 키 원복 | loop-peer-frame 확장 |
