# 공용 달력 (주 규칙 통일, 0.25.1)

상태: 기획 확정(2026-11-02, 시안 dist/proto/week-picker.html 의 B 안 + 일요일 칸 막기). 다음: 구현, QA, 위키.

## 1. 배경

- 앱에 공용 달력이 없다. 기능마다 달력과 주 계산을 새로 만들었다(2026-11-02 조사).
  - 월 달력 격자 3벌: 개인과 열람 `renderMonthBars`(옛 `renderMonthGrid` 포함), 과제 탭 `pcMonthRange`/`pcRenderMonth`, 근태 `atRenderMonth`.
  - 월요일 시작 주 계산 5곳: `calWeekRange`, `pcWeekRange`, `awMonOf`, `weekSubjectGuess`, `weekRange`(+ `rptMPlanDefault`).
  - 요일 이름 배열 7벌: `WEEKDAYS`, `DOW_K` 셋, `WD`, `PC_DOW`, 그 자리 월요일 배열 둘.
  - 주간보고 주 고르기 `awCalRender` 는 따로 만든 월요일 시작 달력이고 공휴일, 주말 색이 없다.
- 인트라넷(사진 확인, 2026-11-02 사용자):
  - 근태 달력과 주간보고 고르기 달력은 일요일 시작이고 한 줄이 한 주다.
  - 주간보고 기간 칸 = 그 줄의 **월~토**(11/10 을 누르면 2026-11-09 ~ 2026-11-14, 제목 "11월 둘째주").
  - 제목 = 보고 있는 달 + 줄 번호(그 달 1일이 든 줄이 첫째 주). 보고 있는 달의 날짜만 누를 수 있다. 달이 걸친 주는 사용자가 고른다(7월 달력에서 27~31 = 7월 다섯째주, 8월 달력에서 1일 = 8월 첫째주).
- **0.25.0 결함**: 앱은 주간 폼 종료일을 일요일(월~일)로 채운다. 인트라넷은 토요일이다. 같은 주 글 찾기(`NcPickSameWeek`, 기간 정확 일치)가 인트라넷에서 직접 쓴 글을 못 알아봐 같은 주 글이 둘 생길 수 있다.

## 2. 정책 (2026-11-02 사용자 확정)

| 이름 | 범위 | 쓰는 곳 |
|---|---|---|
| 달력 한 주 | **일~토**(일요일 시작 달력 한 줄) | 월 달력(개인, 열람, 과제 탭, 근태), 주간보고 주 고르기, 주 제목, 기간 취합의 이번 주/지난주, 그 밖의 모든 주 계산 |
| 주간 보기 범위 | **월~일** | 개인, 과제 탭, 다른 사람 일정의 주간 보기(지금과 같다) |
| 회사 보고 기간 | **월~토** | 인트라넷 주간보고 폼의 기간 칸, 주간보고 DB 기록(`cal_report_weekly`, `cal_report_weekly_hours` 의 `period_start` = 월요일) |

- 주 제목("n월 m째주") = 보고 있는 달 + 일요일 시작 달력의 줄 번호. 기본값은 그 주 월요일이 든 달. 주간 보기 제목도 그 주 월요일이 든 줄로 센다.
- 알고 받아들인 것: 월간에서 일요일을 고르고 주간 보기로 바꾸면 그 일요일로 끝나는 주(한 줄 위)가 열린다. 일요일 당일의 주간 보기는 지난 월~일, 기간 취합의 이번 주는 그날 시작하는 일~토다. 운용에 지장이 없는 표시 차이로 본다(사용자).
- DB 구조와 키는 그대로다. 종료일은 다시 저장할 때 토요일로 덮인다.

## 3. 공용 달력 (한 곳)

웹 `task-calendar-prototype.html` 의 공용 도우미 자리(ymd, addDays 근처)에 둔다. 모든 화면은 이것만 쓴다.

- `CAL_DOW` 요일 이름 하나(일요일부터). 월요일부터가 필요하면 이것을 돌려 쓴다.
- `calRowWeek(ds)` 달력 한 주 { sun, sat }.
- `calViewWeek(ds)` 주간 보기 범위 { mon, sun }.
- `calReportPeriod(ds)` 회사 보고 기간 { mon, sat }(그 날이 든 달력 한 주의 월~토).
- `calMonthGrid(y, m)` 일요일 시작 월 격자 범위 { from, to, weeks }.
- `calWeekTitle(mon, viewY, viewM)` "m월 n째주". 보고 있는 달을 주지 않으면 월요일이 든 달.
- 공휴일(`holidayOn`), 주말 판정, 칸 클래스(주말 색, 공휴일 색, 오늘, 다른 달 흐림)도 공용 함수 하나.
- 디자인: 개인 달력의 칸 모양과 색을 기준으로 근태 달력과 주간보고 주 고르기도 같은 CSS 클래스와 토큰을 쓴다.

## 4. 바꿀 곳

1. 월 격자 3벌을 `calMonthGrid` 와 공용 칸 클래스로.
2. 주간 보기 `calWeekRange`, `pcWeekRange` 를 `calViewWeek` 로(동작 같음).
3. 주간보고: `awMonOf`, `awMonthRows`, `awPickTitle`, `awCalRender` 를 공용으로. 주 고르기를 인트라넷처럼 일요일 시작 달력(보고 있는 달의 월~토 날짜만 누름, 일요일 칸과 앞뒤 달 날짜는 막음, 줄 = 주, 그 줄의 월~토 강조, 줄 머리 n째주)으로. 디자인은 시안 B(개인 달력과 같은 주말, 공휴일 색, 오늘 점). 제목은 `calWeekTitle`.
4. 회사 폼: `awBuildSubmit` 의 `edate` 를 `calReportPeriod` 의 토요일로. 옛 보고서 창 주간 전송(`weekRange`)도 같이.
5. `weekSubjectGuess` 를 `calWeekTitle` 로(근태 주간, 보고서, 목록).
6. 보고서 창 이번 주/지난주(`weekRange`)를 `calRowWeek`(일~토)로.
7. 월간 보고 계획 기본값(`rptMPlanDefault`, 다음 월요일~금요일)은 근무일 범위라 그대로 두되 공용 함수로 계산.
8. 요일 배열 7벌을 `CAL_DOW` 하나로.
