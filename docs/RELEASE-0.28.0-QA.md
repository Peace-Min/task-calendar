### 고친 것(점검 중)
1. 놓을 자리 규칙이 내 과제와 달랐다(가운데 기준). 사용자 지적. 내 과제 규칙으로 맞추고 끌기 코드를 공용 손 `ordDragInit` 하나로 묶음(내 과제, 공식 목록, 날짜 패널). 공식 목록은 틈이나 목록 밖에 놓으면 이제 아무 일도 없다(내 과제와 같음).
2. 부팅 스냅샷: 화면 주입이 실패해도 스냅샷이 바뀌면 다음 저장이 방금 등록한 일정을 지울 수 있었다. 주입이 성공(`__applyState` 가 true)했을 때만 바꿈.
3. 검토 P2: 삭제 실행 취소는 원래 자리로, 반복이 한 날 두 번 그려질 때 끌어 놓기는 대상 id 기준, ordIndexOf 빠른 길 좁힘, 월간 큰 그림 동시 둘과 한 프레임 한 번 그리기, F6 포커스 되돌리기는 사용자 입력이 오면 멈춤.
4. 실DB 시험 `db-project-calendar` 의 낡은 검사(표 수) 고침. 실DB 그림 시험은 첫 실행에서 mysql 출력이 잘려 멈췄다가 다시 돌려 통과(일시 현상으로 봄).
