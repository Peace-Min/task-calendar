# 다음 버전 후보 (0.25.0 다음)

상태: 후보 모음(2026-11-02). 기획 전이다. 하나씩 기획, 개발, QA, 위키 순서로 진행한다.

## 정한 것

1. **첫 설치 기본값: 트레이 켜짐(일반 앱 창)** (2026-11-02 사용자 결정)
   - 지금 첫 설치는 트레이 꺼짐(바탕화면 위젯, 작업 표시줄과 Alt+Tab 에 없음, 늘 맨 아래) + 바탕화면 부착 + 최대화(0.25.0)다. 다른 프로그램을 열면 뒤로 깔려 처음 쓰는 사람이 앱이 떴는지 모른다.
   - 바꿀 곳: `widget/MainWindow.xaml.cs` 의 `WidgetSettings.TrayEnabled` 기본값(지금 false), 필요하면 `Pinned` 기본값. 설정 파일이 이미 있는 기존 사용자는 그대로다.

## 검토할 것

2. **근태 창, 관리 창을 메인 창 안 팝업으로** (+ 전체 크기 단추)
   - 지금 별도 창은 열 때마다 WebView2 를 새로 띄우고 앱 화면 파일 전체(약 2.4MB)를 읽는다. 여는 데 1.5~2.5초(사용자 체감), 창마다 하위 프로세스 하나(추정 70~100MB, 실측 전).
   - 메인 창 안 팝업이면 즉시 열리고 새 프로세스가 없다. 대신 메인 창 밖으로 뗄 수 없다(결정 11, ADMIN-WINDOW 를 되돌리는 일).
   - 다른 사람 일정 창은 나란히 보는 용도라 별도 창을 두고 재사용(닫으면 숨김)만 검토. 껍데기와 열람 프레임이 같은 파일을 두 번 읽는 구조도 본다.
   - 먼저 실측: 세 창의 메모리와 여는 시간. 녹화 중 확인: 근태 창은 닫아도 CDP 대상이 숨은 채 남는다(이미 숨김 재사용인지 확인).
3. **사용 영상 목록 썸네일**: `guide.json` 에 영상별 그림 칸, 호스트 `guideFetch` 가 그 그림도 받게, 빌드가 내보내게, 목록 단추에 그림. v5 영상은 첫 장면이 제목 카드라 재생 화면에는 이미 보인다.
