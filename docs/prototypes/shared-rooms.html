자세히 보기

회의실 목록을 사람마다 따로 두지 않고 회사 공용 목록 하나로 바꿉니다. 목록은 관리자만 관리 화면에서 고치고, 사용자는 장소 칸에서 목록을 골라 쓰거나 아무 장소나 직접 적습니다. 관리 화면에서 바꾼 목록이 위 결정할 것과 일정 입력 창, 빠른 추가에 바로 나옵니다. 실제 앱 화면을 옮긴 것이며 저장은 되지 않습니다.
