버전 관문 차단 화면 시안

서버 DB 구조 번호와 앱이 맞지 않거나 서버가 갱신 중일 때 뜨는 화면입니다. 앱은 켜진 채로 DB 읽기, 쓰기만 막고, 창 안에 카드 하나를 덮어 씁니다(시스템 대화 상자 아님). 위의 단추로 상태를 바꿔 보세요. 카드 안 단추도 눌러 볼 수 있습니다. 근거: docs/DB-RELEASE-OPS.md 3.2, 3.3.

상태
테마
뒤 화면

이 상태

정해 주실 것

  • 뒤 화면: 흐리게 보이기(기본) 또는 가리기. 흐리게 두면 앱이 꺼진 게 아니라는 게 보이고, 가리면 막힌 데이터가 낡은 값으로 읽힐 걱정이 없습니다.
  • 제목줄은 덮지 않았습니다. 막힌 동안에도 창 이동, 최소화, 닫기는 됩니다.
  • 저장되지 않은 변경: 목록만 보여 줄지, 시안처럼 목록 복사 단추를 둘지.
  • 열람 창(9번): 업데이트 단추 대신 창 닫기 단추만 둡니다.
  • 구조 번호 같은 기술 정보는 접힌 "자세한 정보" 안에만 둡니다(담당자 문의용).
  • 담당자 이름, 연락처, 공유 폴더 경로는 자리 표시입니다.
