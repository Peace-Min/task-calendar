내 과제 긴 이름 개선 프로토타입

폭 380px(실제 위젯 폭)에서 같은 데이터를 네 가지 모양으로 비교합니다. 이름 칸에 마우스를 올리면 안 A, C는 전체 이름이 툴팁으로 뜹니다.

권장: 안 A (한 줄 말줄임 + ⋯ 메뉴)

  • 행 높이가 모든 과제에서 같아져 목록이 가지런합니다. ▲▼ 위치도 행마다 같은 자리에 고정됩니다.
  • 동작이 다섯 개(▲▼, 옮기기, 수정, 삭제)에서 ▲▼와 ⋯ 하나로 줄어 이름이 쓸 수 있는 폭이 두 배 가까이 늘어납니다.
  • 전체 이름은 툴팁(마우스)과 이름 줄 누르기(터치)로 봅니다. 수정을 누르면 아래 입력칸에 전체 이름이 그대로 나옵니다.

조사한 상용 앱과 디자인 시스템의 공통 원칙

  • 목록 항목은 한 줄에서 자르고 전체 이름은 툴팁이나 상세로 보여 줍니다(Workday Canvas, Carbon, Maersk).
  • 끝을 자르는 방식은 앞부분이 서로 다른 이름에 맞습니다. 앞이 같은 이름이 많으면 가운데를 줄입니다(Basis). 우리 과제명은 "[샘플] ..."처럼 앞이 같을 수 있어 가운데 줄임을 후속 옵션으로 둡니다.
  • 보조 동작은 ⋯ 메뉴로 모읍니다(Carbon, SAP Fiori). 터치에는 hover가 없으니 hover 전용 동작은 피합니다(Maersk).
  • 잘린 글자가 4자 이상은 남아야 알아봅니다(PatternFly).
