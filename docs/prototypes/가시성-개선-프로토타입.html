일정·할 일 가시성 개선 — 케이스별 Before / After

평가 루프가 짚은 가시성 격차를 케이스별로 현재(Before) 와 개선안(After) 으로 직접 비교합니다. 실제 위젯 칩 스타일을 재현했습니다. 보시고 어느 케이스를 적용할지 골라 주세요.

🟦 보고서(파랑) · 🟩 점검(초록) · 🟧 교육(주황) 과제 예시. 일정=막대형, 할 일=외곽선+원형 링(지난번 적용). 아래 각 그림은 정적 재현이며, 채택하면 위젯에 그대로 구현합니다.

A. 시간 일정 vs 종일 일정 구분 P1

지금은 10:00 회의(시간)와 종일 점검이 똑같은 색막대로 보입니다(시각은 작은 회색 접두사뿐). 개선안: 시간 일정 = 선행 색점 + 굵은 시각, 종일 = 채운 막대 → 월 그리드에서 "점=시간 / 막대=종일"이 한눈에. (Google·Notion Calendar)
