Notion: 버튼으로 블록 삽입선택한 내용을 버튼으로 삽입하는 방식입니다. 과제별 회사 보고 문구로 변환하는 것은 이 시안의 설계입니다.

Slack Canvas: 문서에 자료 모으기자료를 모아 문서로 편집하는 흐름을 참고했습니다. 원본 캘린더와 보고용 문구 편집은 분리합니다.

가상 데이터만 사용합니다. 실제 전송, DB 저장, 로컬 영구 저장은 없습니다. 블록은 작성 도구이며 제출 미리보기에서는 과제별 텍스트로 합쳐집니다.
