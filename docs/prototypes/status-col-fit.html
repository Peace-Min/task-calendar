과제 추가 창: 상태 칸 폭 (2판)

세 목록이 같은 데이터를 보여 줍니다. 검색 칸에 "관제"를 쳐서 "1차 납품완료" 과제를 목록에서 빼 보고, 각 목록의 ⠿ 를 끌어 보세요. 목록 제목 옆 파란 숫자는 지금 상태 칸 폭입니다.

지금

상태 64px 고정. "1차 납품완료"가 잘립니다.

1판: 보이는 줄 기준

잘리지는 않지만, 찾기로 긴 상태 과제가 빠지면 상태 칸이 좁아지고 다른 칸이 넓어집니다(출렁임). 끌면 복제본의 칸이 뭉개집니다.

2판: 기준 줄 + 끌기 복제본 폭 (추천)

보이지 않는 기준 줄이 코드표의 상태 이름 전부와 가장 긴 기간 모양을 들고 있어, 무엇을 걸러도 폭이 그대로입니다. 끌 때는 실제 열 폭을 복제본에 박아 모양이 그대로입니다.

기준 줄은 화면에 높이 0 으로 숨어 있고 읽히지도 않습니다(눈에 보이는 변화 없음). 상태 이름은 코드표에서 받으므로 관리 화면에서 상태를 추가하면 다음에 그릴 때 기준 줄도 따라갑니다. 좁은 창(680px 미만)에서는 지금처럼 상태를 점 하나로 줄입니다.
