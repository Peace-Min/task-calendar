날짜 패널: 일정과 할 일 순서 바꾸기 (A안, 2판)

규칙은 하나입니다. 추가한 순서대로 보이고, ⠿ 를 끌어 바꿉니다. 실제 패널처럼 일정은 5개까지 보이고 나머지는 접힙니다. ⠿ 를 잡으면 접힌 일정까지 전부 펼쳐지고, 끄는 동안 패널 위아래 끝에 가까이 가면 저절로 스크롤됩니다. 놓으면 다시 5개로 접힙니다. 키보드는 카드나 줄에 포커스를 두고 Alt+↑ / Alt+↓ 입니다.

6월 19일금요일

해 볼 것

  1. 맨 아래 보이는 카드의 ⠿ 를 잡아 위로 끌기: 접힌 4개가 펼쳐지고, 놓으면 다시 접힙니다.
  2. "4개 더 보기"를 눌러 펼친 뒤 맨 아래 카드를 패널 맨 위까지 끌기: 끝에 닿으면 저절로 스크롤됩니다.
  3. 카드를 하나 누르고 Alt+↑ 를 여러 번: 한 칸씩 올라갑니다.
  4. 할 일도 같은 방식입니다. 완료한 할 일도 제자리에 남습니다.

왼쪽 월간 칸 (같은 순서)

칸이 넘치면 앞의 5개만 보입니다. 위로 올린 것이 달력에도 보입니다.
