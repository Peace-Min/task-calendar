개발 일정 그림: 붙여 넣기를 보이게

근태 월간 왼쪽 과제 상자. 각 시안의 둘째 줄은 마우스를 올린 모양입니다. 붙여 넣기는 모든 시안에서 Ctrl+V 로도 됩니다.

지금 (0.27.0)

빈 칸을 누르면 파일 고르기. 마우스를 올려 1초쯤 있으면 Windows 풍선이 뜬다.

과제 2/2
개발 일정 그림(파일, Ctrl+V)
풍선이 늦게 뜨고 작아서 Ctrl+V 를 아는 사람만 씁니다.

A. 누르면 둘 중 고르기

빈 칸을 누르면 작은 목록. 붙여 넣기에 단축키를 같이 적어 다음부터는 Ctrl+V 로.

과제 2/2
클릭이 하나 늘지만 메뉴 모양이라 익숙합니다. 클립보드에 그림이 없으면 붙여 넣기를 흐리게.

B. 칸을 둘로

빈 칸을 왼쪽 파일, 오른쪽 붙여 넣기 두 단추로 나눈다. 글 없이 아이콘만.

과제 2/2
붙여 넣기 (Ctrl+V)
클릭 하나로 끝나지만 칸이 작아 아이콘 뜻을 알아보기 어렵습니다.

C. 줄에 올리면 [붙여 넣기]

평소에는 지금과 같고, 과제 줄에 마우스를 올리면 칸 왼쪽에 글 단추가 나타난다.

과제 2/2
눈에 잘 띄지만 마우스를 따라 글이 나타났다 사라져 화면이 출렁입니다.
