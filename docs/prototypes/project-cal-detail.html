과제 탭 날짜 목록 팝업 시안

과제 달력에서 날짜(칸, 막대, +n)를 눌렀을 때 뜨는 그날 일정 목록. 안마다 같은 데이터로 세 경우와 위젯 폭, 좁은 폭을 보여 준다.
데이터는 캡처(now-day-list.jpg)와 같다. 오늘은 10월 30일. 줄을 누르면 상세 창(아래 부차 제안)이 뜨고, D와 E는 상세 창 없이 목록 안에서 끝난다.
