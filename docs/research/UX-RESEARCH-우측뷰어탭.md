# UX 조사 보고서 — 우측 뷰어 기능 탭 (작업 버튼/드로어 대체)

> 작성 2026-06-15 · 방법: 다중 에이전트 워크플로(w1q2zjlys, 4축 병렬 조사 → 종합 → 적대적 검증), 각 앱 WebSearch/WebFetch 확인 + 출처 등급 표기

## 1. 배경 / 질문
- 사용자 피드백: "가장 난잡한 건 '🗂 작업' 버튼이다. 캘린더에서 시작해 TODO·GitLog까지 한 버튼에 욱여넣었고, '작업'을 거쳐 작성하는 흐름이 어색하다."
- 사용자 제안: **우측 뷰어(패널)에 기능별 탭 분리** — 별도 버튼/드로어를 없애고 캘린더 옆 우측 패널 자체를 `[일정 상세 | 할 일 | 작업일지]` 탭 뷰어로.
- 요구: 실제 상용 앱을 조사하고 **어떤 앱을 기준으로 분석했는지 출처까지** 보고.

## 3. 공통 결론 (8개 앱 교차)
1. **전환은 만장일치로 '한 자리에서 단일 선택(라디오)'** — 좁은 패널에 두 기능을 동시 표시하는 앱은 없음. 우리 3탭도 한 번에 하나만.
2. **상세와 태스크를 섞지 않고 '캘린더에서 무엇을 선택했는가'에 종속** — 우리 `selectedDate`가 이미 전역이라 '날짜 클릭=일정 상세 탭'이 거의 공짜로 성립(단 다른 탭에서 날짜 클릭 시 상세로 전환하는 1줄 추가 필요).
3. **생성은 전 앱 공통 '인라인 한 줄(모달 금지)'** — 우리 `quickAddHtml`이 이미 이 패턴. 모달은 '깊은 편집' 전용으로만(Outlook 2단).
4. **탭 3~5개 가드레일(VS Code 공식)** — 보고서는 탭이 아니라 헤더 액션 버튼.
5. **기본 탭 = 앱의 일차 작업(=일정 상세)**. 보조 기능(작업일지)을 기본으로 두면 안 됨.
6. **접기/숨기기 1급 기능** — 분할바를 0까지 접어 '월그리드 전용' 상태 제공.

## 4. 판정 (검증 통과)
**사용자 제안은 옳다 — 채택 권장.** `🗂 작업` 버튼 + 오버레이 드로어 + 스크림을 제거하고 기존 우측 `.day-panel`을 `[일정 상세 | 할 일 | 작업일지]` 세그먼트 탭 뷰어로 승격. 가장 직접적 선례는 **Outlook 'My Day'**(우리와 1:1), 뒷받침은 VS Code·IntelliJ·Google·Notion. 난잡함의 객관적 원인 = "캘린더 옆에 이미 우측 표면(.day-panel)이 있는데 또 다른 우측 드로어(.note-drawer)를 띄워 우측 표면이 둘로 갈린 것"이며, 이를 제거하면 표면 2→1, 진입 동선 '버튼 경유 → 날짜 클릭 직결'로 개선됨.

## 5. 정직한 단서 (검증 에이전트 교정)
- **380px에선 '우측 뷰어'가 성립하지 않음**: 위젯 실폭이 760px 미만이라 패널은 항상 캘린더 '아래'로 스택. 같은 기능이 **넓을 땐 우측 패널, 좁을 땐 하단 시트**로 모델이 바뀐다 — 좁은 폭 동작을 P0에서 함께 정의해야 함(P2로 미루면 데스크톱에서만 멀쩡).
- **P0는 '함수 재활용'만으론 안 됨**: `renderDayPanel`이 패널을 통째 innerHTML 교체하므로 '탭바 보존 + 본문만 교체'로 구조 분리 필요. 드로어 핸들러(#ndBody/#ndFilter/탭)를 #dayPanel로 재배선 + 기존 카드 클릭 핸들러와 통합. 과제 필터칩(nd-filter)도 함께 이식해야 할 일의 과제 자동분류가 유지됨.
- **순감(net)은 '버튼 1 + 오버레이/스크림 1겹 + open/close/toggle 3함수'** — 렌더 총량은 대부분 이전됨. 진짜 편의성은 **P1(인라인 생성 일원화)** + 상태 영속화 + 좁은 폭 reflow가 구현돼야 체감(P0만 하면 '덜 난잡하지만 더 빽빽').

## 6. 구현 단계
- **P0 (구조 정리)**: 작업 버튼/드로어/스크림 제거 → .day-panel을 탭 컨테이너로(탭바 보존+본문 교체 분리), renderDayPanel=일정 상세 탭, renderTodoListTab/renderGitTab을 나머지 탭으로 라우팅. '오늘' 탭은 '할 일' 상단 [지남][오늘] 섹션으로 흡수(3탭 유지). 보고서는 탭바 우측 액션으로. **좁은 폭 동작 동시 정의**.
- **P1 (생성 일원화)**: '일정 상세' ＋추가를 인라인 빠른 행(제목+종일/시간)으로, 상세만 entryModal 승격. 선택 탭/과제필터/접힘 localStorage 영속화.
- **P2 (좁은 폭 reflow)**: 42% 세로 스택 폐기 → '캘린더 전체폭 ↔ 하단 60% 시트' 단일 토글, 탭바 sticky. 분할바 0까지 접기. 넓게 보기에선 좌우 분할 유지.
- **P2+ (선택)**: 드래그-투-스케줄(380px 과욕 — 보류 권고).
