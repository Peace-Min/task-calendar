# 과제 목록 묶음: 보기 팝업, 근태 추가 목록, 월간 상자

상태: 구현(2026-11-16, 다음 판). 기획 2026-11-13 사용자 시안 확정. 시안 `docs/prototypes/category-lists-groups.html` 1~4번의 after. 조사 `docs/CATEGORY-LIST-SCREENS.md`, 앞선 작업 `docs/CATEGORY-GROUPS.md`(내 과제 묶음 A').

## 1. 결정
1. **묶음 규칙은 내 과제와 같다.** 공식(`catGroupRank` 0), 일반(1), 기본(휴가 2, 기타 3) 순서이고 묶음 안은 `state.categories` 순서다. 머리 모양도 내 과제 창 A' 와 같은 색 규칙이다.
   - 공식 과제 머리: 옅은 파랑(강조색 옅은 바탕과 글자).
   - 일반 과제 머리: 표 머리 회색 바탕.
   - 기본 머리: 바탕 없이 위쪽 굵은 경계선.
   - 머리에는 묶음 이름과 개수(예: "공식 과제 3"). 비는 묶음은 머리도 없다.
2. **개인 달력 보기 팝업(과제 필터, 다른 사람 일정 보기 팝업도 같은 함수):**
   - 순서를 기록 수 순에서 내 과제 순서로 바꾼다. 0건 구분선(`fb-gap`)은 없앤다. 0건 과제는 제자리에서 흐리게(지금 `zero` 모양) 둔다.
   - 묶음 머리를 넣는다. 찾기로 거르면 남은 과제가 없는 묶음은 머리도 숨기고, 머리 개수는 보이는 줄 수다.
   - 머리는 고를 수 없는 줄이다. 화살표 이동, 전체 선택, 전체 해제, 클릭 대상에서 빠진다(`.fb-opt` 아님, `role="presentation"`).
   - 숫자 두 칸, 찾기, 전체 선택, 전체 해제는 그대로.
3. **근태 일간 [과제 추가], 근태 주간 과제투입시간 추가:** 순서는 이미 내 과제 순서다. 묶음 머리만 넣는다. 찾기와 머리 규칙은 2번과 같다. 머리는 체크 대상이 아니고 전체 선택, 해제에 들어가지 않는다.
   - 근태 창(ATTENDWIN)은 과제 목록을 메인 창이 보낸 payload 로 받는다. 각 과제에 묶음 번호를 함께 실어 보내고, 근태 창은 그 번호로 머리를 그린다. 번호가 없는 옛 payload 면 머리 없이 지금처럼 그린다.
4. **월간 왼쪽 상자:** 상자 이름(과제, 기타), 머리 체크와 개수, 그림 칸은 그대로다.
   - 과제 상자 머리 바탕을 옅은 파랑(공식 과제 머리와 같은 색)으로 한다.
   - 기타 상자 안에서 일반 과제 다음 첫 기본 과제(휴가 또는 기타) 줄 위에 굵은 경계선을 둔다. 일반 과제가 하나도 없거나 읽은 뒤 기본 과제만 남으면 선이 없다.
   - 월간 보고서의 과제 표, 기타 표 내용과 순서는 바뀌지 않는다(화면 모양만).
5. **바꾸지 않는 곳:** 근태 일간 블록 순서, 주간 시간 줄, 입력 창과 찾기 창의 과제 고르기 상자, 내보내기, 합치기 대상, 연결 목록, 보고서, 주간 과제별 줄, 밀린 할 일, 과제 탭. 이미 내 과제 순서이고 줄마다 이름이 보인다(머리를 넣으면 줄 높이가 출렁인다).

## 2. 결함 후보 3건(조사 문서 §결함)의 처리
- 1(내보내기에 삭제된 공식)과 3(보기 팝업에 삭제된 공식)은 고치지 않는다. 삭제된 공식 과제라도 내 캘린더에 기록이 남아 있으면 그 기록을 내보내거나 달력에서 거를 수 있어야 한다. 의도된 동작으로 적어 둔다.
- 2(근태 목록이 이름으로 중복을 거름)는 고치지 않는다. 근태 블록과 인트라넷 전송이 과제 이름을 키로 쓰기 때문에 같은 이름 두 줄을 따로 다룰 수 없다. 이름을 바꾸라는 안내가 맞는 길이다. 이번 작업에서 묶음 머리 개수는 화면에 실제 보이는 줄 수로 세어 어긋나지 않게 한다.

## 3. 시험
- 보기 팝업: 내 과제 순서, 0건 제자리 흐림, 구분선 없음, 묶음 머리 셋과 개수, 찾기로 빈 묶음 머리 숨김, 머리는 화살표와 전체 선택 대상 아님. 다른 사람 일정 보기 팝업도 같은 모양.
- 근태 일간, 주간 추가 목록: 머리 셋, 찾기, 체크와 전체 선택이 머리를 건드리지 않음, 묶음 번호 없는 payload 는 머리 없이.
- 월간: 과제 상자 머리 class, 기타 상자 휴가 위 선(일반 과제가 있을 때만), 보고서 결과 불변.
- 고친 시험: filter-multi 의 기록 수 순서 고정은 새 순서로 바꾼다.
