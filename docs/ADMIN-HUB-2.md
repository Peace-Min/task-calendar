> 2026-10-02, 대상 v0.19.x, 파이프라인은 기획, 개발, QA, 위키 순. 앞 단계 [`ADMIN-HUB.md`](ADMIN-HUB.md)(구현 727f27b) 위에 얹는다.

## 0. 사용자 지적(2026-10-02)과 결정

| # | 지적 | 결정 |
|---|---|---|
| 1 | 관리 버튼이 ☰(위젯 창 설정: 부착, 크기, 트레이, 종료)에 있는 건 **레벨이 안 맞는다** | 입구를 **⋯ 메뉴**(설정, 회의실 관리, 데이터 등 앱 기능이 있는 곳)로 옮긴다. ☰ 은 원래대로 두고 **C# 변경(727f27b 의 ShowSettingsMenu(admin))을 되돌린다** |

| 3 | 설명글이 '최근 본 사\|람'처럼 단어 중간에서 줄바꿈되어 문맥이 끊긴다 | 앱 전체에 **한국어 단어 단위 줄바꿈**(`word-break: keep-all`, 넘칠 때만 `overflow-wrap: anywhere`). `「」` 인용은 한 덩어리로 두고, 그 안내문은 다듬는다 |
| 4 | 사용자 정보의 '구성원 보기'와 '관리' 카드가 의미가 없어졌다 | 사용자 정보는 **계정, 권한, 로그아웃**만 둔다. 구성원 줄(구성원 보기, 구성원 편집)과 관리 카드를 없앤다. '구성원 보기' **창 코드는 이번엔 남긴다**(입구만 없앤다. 시험 다수가 쓰므로 다음 정리 때 시험과 함께 걷는다) |

## 1. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| J1 | ⋯ 메뉴 입구 | ⋯ 메뉴에 **'⚙ 관리'와 '관리자' 꼬리표**를 둔다. 관리자(edit_role=admin)로 확인된 때만 보인다(모르면 숨김, 지금의 판정과 캐시 그대로). 누르면 ⋯ 를 닫고 관리 화면(마지막 항목)을 연다. 닫으면 ⋯ 버튼으로 포커스가 돌아온다. 위치는 '설정' 바로 위(앱 기능 묶음의 맨 앞)이고, 구분선으로 접기 항목들과 나눈다 |
| J2 | ☰ 원복 | ☰ 클릭은 예전처럼 `{cmd:'menu'}` 만 보낸다(admin 필드 없음). `widget/MainWindow.xaml.cs` 는 **727f27b 이전과 바이트 동일**하다(줄끝 포함, `git show 727f27b~1:widget/MainWindow.xaml.cs` 와 같아야 한다). `window.__openAdminHub` 는 쓰는 곳이 없으면 없앤다 |
| J3 | 찾아보기 읽기 전용 | `#officialModal` 을 **단독**으로 열면(내 과제에서 찾아보기, 그 밖의 단독 경로) 관리자여도 '＋ 새 공식 과제', 상세의 편집/숨김 등 쓰기 동작, 아래 줄의 '발주처 관리', '구분·상태 관리', '🗑 휴지통'이 **보이지 않는다**. 남는 것: 검색과 필터, 목록, 상세, **'내 캘린더에 추가'**, 지금 새로고침, 닫기, Excel 추출(지금 보이는 조건 그대로). 관리 화면에 도킹된 공식 과제는 지금처럼 편집할 수 있다(그 화면의 발주처, 구분/상태, 휴지통 버튼은 이미 도킹 때 감춘다) |
| J4 | 내 과제 관리자 링크 | '⚙ 공식 과제 편집은 관리에서 ›'는 유지한다(관리자만). 찾아보기가 읽기 전용이 되므로 편집으로 가는 유일한 문맥 문이다 |
| J5 | 사용자 정보 | '구성원' 줄(설명, 구성원 보기, 구성원 편집)과 '⚙ 관리' 카드를 **화면에서 없앤다**. 남는 것: 계정(로그인 상태, 이름, 직급, 소속, DB 연결), 권한(편집 권한, 열람 범위, 지금 새로고침), 로그아웃, 닫기. '구성원 보기' 모달(#membersModal)과 openMembers 는 코드로 남긴다(입구 없음, 주석으로 "다음 정리 때 시험과 함께 제거" 표시) |
| J6 | 한국어 줄바꿈(전역) | 앱 전체 글에 `word-break: keep-all` 과 `overflow-wrap: anywhere`(긴 경로나 ID 처럼 칸을 넘칠 때만 글자 단위)를 건다. 입력칸, 코드/경로 전용 표시, 표는 넘침 검사로 확인한다. **레이아웃 회귀 금지**: layout-stability, loop-ui-visual, loop-ui-integrity 무회귀. 깨지는 곳이 있으면 그 요소만 국소 예외로 둔다 |
| J7 | 인용 덩어리 | 화면 문구 속 `「…」` 인용이 줄 끝에서 갈라지지 않게 한다(필요한 곳은 `white-space: nowrap` 으로 감싼다. 전역 일괄 치환은 하지 않고, 사람 고르기 안내 같은 짧은 안내문 위주로) |
| J8 | 안내문 다듬기 | 사람 고르기 처음 안내: "☆ 를 누르면 즐겨찾기에 남습니다. 한 번 연 사람은 최근 목록에 쌓입니다."(두 문장, 인용 없음). 같은 결의 짧은 안내문 몇 개를 실 위젯 폭 360px / 1380px 에서 눈으로 점검한다(캡처) |
| J9 | 지키는 것 | 권한 판정은 호스트, 새 호스트 명령 없음, 관리 화면 동작(ADMIN-HUB H1~H13)은 그대로(입구만 바뀜), 테마 토큰, DB 문자열은 textContent |
