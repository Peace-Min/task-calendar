# 개인 달력: 날짜 패널 정리와 보기 필터 하나 (0.26.0)

상태: **구현 완료**(2026-11-03, 시험 tests/personal-panel.test.mjs, 위키 [개인 달력 패널](wiki/개인-달력-패널.md)). 기획 확정은 2026-11-03 사용자, 시안 dist/proto/personal-panel.html. 관련 이슈 #15(1단계). 다음: 배포 때 버전 번호(0.26.0 예정).

## 1. 배경

- 개인 달력에서 일정과 할 일이 섞여 복잡하다(#15). 화면에 탭과 토글이 많다(개인/과제/근태, 월간/주간, 우측 패널의 일정 상세/할 일).
- 우측 패널의 [일정 상세 | 할 일] 탭은 패널 하나에 "그날 기록"과 "할 일 전체"를 겹쳐 놓은 것이다(2026-06-16 첫 판부터).

## 2. 결정

### 2.1 우측 패널 = 고른 날짜만
- 위의 [일정 상세 | 할 일] 탭을 없앤다.
- 머리: 날짜, 요일, **[+ 추가]** 하나. 누르면 지금 입력 창을 그 날짜로 연다(종류는 입력 창 위의 [일정 | 할 일] 에서 고른다. 보기가 할 일만이면 할 일로 연다).
- 본문: **일정 n / 할 일 n 두 묶음을 늘 같은 자리에** 보인다. 비면 "없음", 보기에서 끈 종류는 "보기에서 숨김". 날짜를 바꿔도 패널 모양이 출렁이지 않는다.
- 할 일은 중요(★) 먼저, 줄 끝 ★ 로 켜고 끈다. 체크로 완료.
- 맨 아래 고정 한 줄: **"할 일 전체 보기 … 기한 없음 n ›"**. 누르면 할 일 전체 팝업(★ 중요, 기한 지남, 이번 주, 나중, 기한 없음, 완료 묶음). 날짜 있는 할 일을 누르면 그 날짜로 이동하고 강조. 지금 할 일 탭이 하던 일을 옮긴다.
- 달력에서 할 일 칩을 누르면 그 날짜가 선택되고 패널에서 그 할 일이 강조된다(탭으로 넘어가지 않음, 일정 칩과 같은 동작).

### 2.2 도구줄
- **"+ 새 기록" 단추를 없앤다.** 추가는 패널의 [+ 추가]. 날짜 두 번 누르기로 바로 여는 길은 남긴다. 좁은 창(패널이 아래 시트)에서는 날짜를 누르면 시트가 뜨고 그 안의 [+ 추가].
- 과제 필터 단추를 **보기 단추 하나**로 넓힌다: 이름 "⚲ 보기", 기본 상태가 아니면 단추가 강조되고 요약이 붙는다(예: 보기 할 일만, 보기 과제 2, 완료 숨김, 중요만).

### 2.3 보기 팝업 (필터 하나로 묶기)
- 머리 "달력에 보일 것" + [처음대로].
- **기록 종류**: 일정, 할 일(둘 다 끌 수는 없다).
- **과제**: 전체 선택/해제, 과제 목록(지금 다중 선택 필터 그대로, docs/FILTER-MULTI.md).
- 가는 선 아래 **보기 옵션**: 완료한 할 일 표시, 중요한 할 일만. 상용 앱처럼 "무엇을 보일지"와 "어떻게 보일지"를 나눈다(Google 캘린더 보기 옵션, TickTick, Todoist).
- 월간 칸, 주간 과제별 줄, 우측 패널, 할 일 전체 팝업이 같은 보기를 따른다. 고른 보기는 계정별 이 PC 에 기억(지금 필터 저장과 같은 곳).

### 2.4 달력 칸
- 일정과 할 일이 둘 다 보일 때: 칸 맨 위 줄에 그날 할 일을 모으고(3개 이상이면 "할 일 n" 개수), 점선 아래 일정. 할 일만 또는 일정만이면 나누지 않는다.
- 중요한 할 일은 제목 앞 ★.

## 3. 구현 원칙

- 지금 함수를 고쳐 쓴다: 패널(`renderPanel`, `dayDetailHtml`, `renderTodoListTab`), 필터(filterPop*, FILTER-MULTI), 칸 그리기(`renderMonthBars`, 주간 `renderWeekRows`), 입력 창(`openQuickAdd` 류). 할 일 전체 팝업은 공용 모달(openModal) 골격으로, `renderTodoListTab` 의 묶음 계산을 옮겨 쓴다.
- 공용 달력과 칸 클래스(CALENDAR-COMMON), 토큰만. 새 hex 색 금지.
- 다른 사람 일정 보기(열람 프레임)는 같은 함수를 쓰므로 읽기 전용에서 [+ 추가], ★, 체크가 안 보이는지 확인한다.

## 4. 하지 않는 것

- 우측 패널 제거(#15 2단계), 할 일 입력 창 통합.
- 과제 탭, 근태 탭 화면.

## 4-1. 구현에서 정한 것

- **여러 날 할 일은 칸 맨 위 줄로 모으지 않는다.** 하루짜리 할 일(기한만 있는 것)만 맨 위 줄에 모인다. 여러 날 할 일은 여러 날 일정처럼 점선 막대로 남고 점선 아래 일정과 같은 차선을 쓴다(막대를 날마다 쪼개면 기간이 안 보이고 제목이 날마다 반복된다).
- **주간 과제별 줄은 나누지 않는다.** 과제 줄 안에서 할 일을 위로 모으지 않고 보기(종류, 옵션, 과제)만 따른다. 칸 맨 위 줄은 월간 칸의 규칙이다.
- **할 일 전체 팝업의 중요 묶음은 겹친다.** 안 끝낸 중요 할 일은 ★ 중요 묶음과 제 묶음(기한 지남 등)에 모두 나온다(시안과 같다). 이번 주는 오늘부터 그 달력 한 주(일~토) 끝까지다.
- **팝업과 맨 아래 개수는 기록 종류 끔을 따지지 않는다.** 기록 종류를 "일정만"으로 해도 할 일 전체 팝업과 "기한 없음 n" 은 과제, 완료 표시, 중요만을 따라 할 일을 보여 준다.
- **정렬**은 시안과 같이 중요 먼저, 같은 중요도에서 안 끝낸 것 먼저다(끝낸 중요 할 일이 안 끝낸 보통 할 일보다 위에 온다).
- **기억**: 계정별 이 PC(localStorage `tc_view:<계정>`)에 종류, 옵션, 고른 과제를 저장한다. 처음 상태면 지운다. 없어진 과제는 빼고, 선택 없음(과제 0)은 되살리지 않는다. 열람 창은 기억하지 않는다.
- **보기 단추**: 고른 과제 칩과 +N 은 없앴다. 과제가 없어도 단추는 켜져 있다(기록 종류, 보기 옵션을 쓴다). 좁은 창에서 아래 시트가 열려 있으면 팝업을 열기 전에 시트를 닫는다.
- 날짜 두 번 누르기도 [+ 추가]와 같은 종류 기본값을 쓴다(보기가 할 일만이면 할 일).
