# 화면 혼란 3건 정리 — 기획서

> 2026-10-01 · 대상 v0.19.x · 파이프라인 **기획 → 개발 → QA → 위키** 의 1단계 산출물. 개발·QA 의 정본.

## 0. 요구(사용자 2026-10-01)

1. 「넓게 보기」 버튼 이름이 부적절하다 — 이 버튼은 넓게 보기가 아니라 **앱을 맨 앞(최상단)으로 띄우는** 버튼이라 혼란을 준다.
2. 보고서 전송의 「테스트 모드 / 실제 작성 모드」 자체가 혼란을 준다 — **무조건 실제 작성으로 고정**.
3. 트레이 모드에서 ✕ 를 누르면 최소화(트레이로)가 맞다 — 그러면 최소화 버튼은 필요 없어지나?

## 1. 현재 동작(조사)

| # | 지금 | 근거 |
|---|---|---|
| 1 | 제목줄 ⤢ 버튼 · ☰ 메뉴 「넓게 보기」 = 창을 화면 가운데 **1100×800(작업 영역의 90% 이하)으로 키우고, 모든 창 위(topmost)에 띄우고, 뒤를 어둡게** 한다. Esc · 같은 버튼으로 닫으면 원래 자리·크기·Z순서로 돌아간다 | `OpenBig`/`CloseBig` · `#hbFocus` |
| 2 | 설정의 「회사 전송 모드」 라디오(`tc_netcusMode`)가 **기본 「미제출 테스트」**. 보고서 창에 배지 「미제출 테스트 모드 / ⚠ 실제 제출 모드」. 테스트면 사이트에 쓰기 직전 화면만 보여 주고 제출하지 않는다 | `ncMode()` · `#rptSendMode` · 호스트 `DryRun` |
| 3 | 트레이 사용 시 ✕ = **이미 트레이로 숨기기**(종료 아님). 「_」(`#hbHide`)도 트레이로 숨기기 — **둘이 똑같다**. 종료는 ☰ 메뉴·트레이 메뉴의 「종료」. 트레이 미사용 시 ✕ = 종료, 「_」 는 안 보인다 | `case "close"`/`"hide"` · `#hbHide` |

## 2. 목표 동작

| # | 동작 |
|---|---|
| U1 | 버튼·메뉴 이름을 **「맨 앞에 띄우기」**로 바꾼다. 툴팁: 「맨 앞에 띄우기 — 다른 창 위에 크게 띄워 작업합니다 (Esc 로 해제)」, 켜진 상태: 「맨 앞 해제 (Esc)」. 아이콘은 확대(⤢)가 아니라 **앞으로 가져오기**를 뜻하는 모양(겹친 창 중 앞 창)으로. 동작은 그대로(크게 + 맨 앞 + 뒤 어둡게) |
| U2 | 사용 안내·설정 안내 문구의 「넓게 보기」를 새 이름으로(과거 버전 패치노트는 기록이라 그대로) |
| U3 | 보고서 회사 전송은 **늘 실제 제출**. 설정의 「회사 전송 모드」 라디오와 보고서 창 배지·버튼 톤 분기를 없앤다. 예전에 저장된 `tc_netcusMode` 값은 무시(읽지 않는다) |
| U4 | 실제 제출 전 확인은 **지금 있는 확인 절차를 그대로** 둔다(없다면 한 번 묻는 확인을 둔다 — 「회사 보고 시스템에 실제로 제출합니다」) |
| U5 | 트레이 사용 시 제목줄의 「_」(트레이로 숨기기) **버튼을 없앤다** — ✕ 가 같은 일을 한다. ✕ 툴팁을 상황에 맞게: 트레이 사용 「트레이로 숨기기 (종료는 ☰ 메뉴)」 / 미사용 「닫기(종료)」 |
| U6 | 호스트 동작(✕=트레이 / 종료 경로 / 미저장 경고)은 바꾸지 않는다 |

## 3. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| V1 | 제목줄 버튼 툴팁·☰ 메뉴 항목이 「맨 앞에 띄우기」, 켜면 「맨 앞 해제 (Esc)」 · 아이콘 교체 | 계약 + 실 위젯 |
| V2 | 앱 안 「넓게 보기」 문구가 사용 안내·설정에서 사라짐(과거 패치노트 제외) | 계약 |

| V5 | 좁은 폭(320~440)에서 제목줄 버튼 줄 무회귀 | loop-ui-visual |
| V6 | 기존 스위트·루프 무회귀 | strict · run-loops |
