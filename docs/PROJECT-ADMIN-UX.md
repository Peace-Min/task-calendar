# 과제 관리 화면 개선 기획 (사업부 인계 전)

정한 날: 2026-10-26(사용자). 상태: 기획(개발 전).
배경: 사업부에 넘기기 전에 관리 창(회사 과제)을 사업부 엑셀 장표처럼 쓰게 한다. 과제 데이터 최신화 SQL 은 비공개 저장소 taskmgr-company-data 의 project-data/ 에 따로 있다.

## 1. 바꾸는 것

### 1.1 과제 순서(No)
- 사업부 엑셀은 구분 묶음 안에서 No 순서로 과제를 둔다. 지금 앱은 순서 칸이 없어 통상명칭 가나다순이다.
- `project.sort_no`(INT UNSIGNED NULL) 칸을 더한다. 구조 18 에서 19(이관 조각 `v19-project-order.sql`, 0.24.0 에 18 과 함께 나간다). 칸 추가만이라 기존 데이터는 그대로다.
- 화면의 No 는 "그 구분 안에서 몇 번째인가"다(구분마다 1부터). 정렬은 구분 순서, sort_no(빈 값은 뒤), 통상명칭.
- 옮기는 방법(시안 C, 사용자 선택): 상용 앱(Trello, Jira) 방식.
  - 행 왼쪽 손잡이를 끌어 같은 구분 안 다른 자리에 놓는다.
  - 행 오른쪽 ⋯ 메뉴: 맨 위로, 한 칸 위로, 한 칸 아래로, 맨 아래로, N번째로 이동.
  - 옮기면 그 구분의 보이는 과제 전체에 1부터 번호를 다시 매겨 저장한다.
  - 거르기(상태 체크, 발주처, 검색)가 켜져 있으면 끌기는 막는다(일부만 보일 때 놓을 자리가 애매하다). ⋯ 메뉴의 번호는 늘 전체 목록 기준이다.
  - 저장은 구분 하나의 순서 전체를 한 번에 보낸다. 그사이 다른 관리자가 그 구분의 과제를 바꿨으면(목록이 다르면) 거부하고 새로 고침을 안내한다(구분, 상태 순서 바꾸기와 같은 방식).
  - 권한은 과제 편집과 같다.
- 새 과제, 구분을 바꾼 과제, 휴지통에서 되살린 과제는 그 구분의 맨 뒤로 간다.
- 같은 순서를 따르는 곳: 관리 목록, Excel 추출, 내 과제의 '공식 과제 찾아보기'와 재연결 고르기. 개인 캘린더의 과제 순서(내 과제 ▲▼)는 사람마다 따로라 그대로다.
- 과제 최신화 SQL 은 엑셀 No 순서로 sort_no 를 채우도록 다시 만든다(구조 19 이상에서만 돈다. 폐쇄망 순서: 0.24.0 배포 SQL, 그다음 최신화 SQL).

### 1.2 상태 거르기: 체크박스
- '진행중만' 체크(실제로는 상태 '종료' 하나만 빼던 특별 규칙)를 없앤다.
- 상태표의 상태마다 체크박스를 하나씩 자동으로 만든다(상태 없음이 있으면 그것도). 기본은 모두 켬. 고른 것은 이 PC 에 기억한다.
- 상태를 더하거나 이름을 바꿔도 체크박스가 따라갈 뿐 규칙을 따로 고칠 것이 없다.
- 관리 목록, Excel 추출(지금 거른 그대로 뽑고 부제에 뺀 상태를 적는다), 재연결 고르기에 같은 체크박스를 쓴다.

### 1.3 참조 id 삭제
- 과제 상세의 `참조 id: db-…` 줄을 지운다. 사업부 사용자에게 의미가 없다.

### 1.4 연결 규칙 삭제(구분, 상태와 날짜는 서로 독립)
- 선진행이면 계약 날짜와 상태를 비우고 잠그는 규칙을 지운다(화면과 호스트 둘 다. 호스트는 지금 말없이 NULL 로 덮는다).
- 선진행으로 바꾸면 자동 개발 날짜를 비우는 규칙을 지운다.
- 선진행(구분 2), 종료(상태 2) 코드 행을 숨기거나 지우지 못하게 하던 보호를 지운다(그 규칙들 때문에 있던 보호다). 관리 화면, 휴지통, 설치 스크립트(setup-taskcalendar.ps1)의 강제도 지운다. 지난 이관 스크립트(migrate-2026-10-15)는 기록이라 두고, 그 시험은 기록으로 남긴다.
- 정본 스키마의 표 설명(COMMENT)에서 '고정 번호 2 = 선진행, 종료' 문구를 지운다(v19 가 같은 문구로 COMMENT 를 바꾼다).
- 남기는 것:
  - 새 과제의 개발 날짜 기본값(계약 시작 + 1달, 계약 종료 - 1달). 손으로 고치면 그대로다.
  - 상태 색(진행중 초록, 1차 납품완료 파랑, 종료 회색)은 표시만이다.
  - 비슷한 과제 등록 확인창.
  - 날짜 순서, 필수 칸, 이름 중복 금지 같은 무결성 규칙.
- 과제 공용 캘린더가 숨긴 과제(is_active = 0)를 "종료, 읽기 전용"이라 하던 문구를 "숨긴 과제, 읽기 전용"으로 바꾼다(상태 종료와 헷갈림).

## 2. 순서
기획(이 문서) 다음 개발(호스트와 DB, 웹을 나눠 동시에) 다음 QA(전체 strict, 실제 위젯, 복제 DB 에 v19 와 최신화 SQL) 다음 위키.
