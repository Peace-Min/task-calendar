# 캘린더 오늘 표시 동기화

상태: 방식 확정 (2026-11-13). 구현 상세(대상 칸, 코드 모양, 시험)는 docs/DAY-ROLLOVER-FABLE.md 를 기준으로 한다.

## 배경과 범위

달력은 그릴 때 PC의 지역 날짜를 읽어 오늘에 색을 붙인다. 앱을 계속 켜 두면 자정에 달력을 새로 그릴 계기가 없어 어제 칸에 표시가 남는다.

사용자가 정한 범위는 **OS 지역 날짜에 맞춰 달력의 오늘 표시만 갱신**하는 것이다. 선택 날짜, 보던 월과 주, 키보드 초점, 열린 팝업과 편집 값은 유지한다. 과제 및 근태 데이터 조회, 시작 알림, DB와 호스트 변경은 이번 범위 밖이다.

구현안은 개인 달력, 열람 달력, 과제 달력, 근태 일간 달력에 이미 있는 오늘 표시를 대상으로 한다. 한 화면에 달력이 나란히 보이면 각각 갱신한다.

## 기존 동작과 범위 밖 항목

- **탭 전환.** 개인, 과제, 근태 일간 달력은 다른 탭에서 들어올 때 기존 렌더링으로 PC의 지역 날짜를 새로 읽는다. 자정 타이머는 같은 탭을 켜 둔 채 날짜가 바뀌는 경우를 처리한다.
- **패널 날짜 문구.** ‘지남 n’, ‘오늘’, ‘내일’, ‘어제’는 다음 패널 렌더링까지 이전 날짜 기준으로 남을 수 있다. 개인 탭에 돌아오거나 날짜 칸을 선택하면 다시 계산된다.
- **선택 날짜와 보기 범위.** 탭을 전환해도 선택일과 보고 있던 월·주는 유지된다. 오늘로 이동하려면 [오늘] 버튼을 누른다.
- **근태 키보드 진입.** 오늘 색을 갱신할 때 기존 `tabindex`와 초점은 유지한다. 일간 달력을 다시 열면 Tab 진입 위치도 새 오늘을 기준으로 계산한다. 새 오늘 칸이 화면 밖일 때 달력에 Tab으로 들어갈 수 있는지는 QA에서 별도로 확인한다.
- **시작 알림.** 탭을 전환해도 호스트의 알림 대상 목록은 갱신되지 않는다. 앱을 며칠 켜 둔 뒤 알림이 누락되는 문제는 별도 버그로 다룰 것을 권한다. 별도 수정의 목표는 장시간 실행 중에도 대상 목록을 갱신하는 것이다. 목록을 오늘부터 +7일까지 늘릴지는 절전 복귀 요구를 정한 뒤 결정한다.

## 동작

- 다음 지역 자정과 창이 다시 보이거나 포커스를 받을 때 `todayYmd()`로 날짜를 확인한다.
- 날짜가 달라지면 기존 칸의 `.today` 클래스를 갱신한다. 새 오늘 칸이 현재 그려져 있으면 그 칸에 표시한다. 화면에 없으면 옛 표시만 지운다.
- 접근성 이름에 이미 날짜를 안내하는 칸은 ‘오늘’ 표기도 함께 갱신한다. 공휴일명, 일정 건수와 같은 나머지 이름은 보존한다.
- 예를 들어 11월 30일 밤에 11월을 보고 있다가 12월 1일이 되면 11월을 계속 본다. 12월 1일 칸이 그 화면에 있으면 그 칸에 오늘 표시가 붙는다.

## 구현 순서

1. `task-calendar-prototype.html`의 기존 `todayYmd()`와 달력 칸 구조를 재사용한다. 대상은 달력 영역 안의 날짜가 있는 `.cal-c` 칸이다. 개인 및 근태와 과제 월간은 `data-date`, 과제 주간 머리는 `data-hdate`를 읽는다. 기존 렌더링도 계속 오늘 표시를 만든다.
2. 날짜가 바뀌면 현재 칸의 클래스와 접근성 속성만 수정한다. 달력 전체 렌더링이나 날짜 선택 함수를 호출하지 않는다. 누르기나 키 입력을 감시할 필요가 없다.
3. 메인 문서와 열람 프레임마다 타이머를 하나 둔다. 다음 자정은 지역 날짜의 다음 날 0시로 계산한다. 타이머가 실행되면 다음 자정 예약을 먼저 잡고 표시를 갱신한다. 창 복귀 시에는 날짜가 같아도 다음 자정 예약을 다시 계산한다. 같은 날에 PC 시각을 조정했을 수 있기 때문이다. 문서를 떠날 때 예약을 지우고 뒤로 가기 캐시에서 복귀하면 다시 시작한다.

앱이 실행 중이고 자정 타이머가 동작하면 자동으로 표시가 바뀐다. 절전이나 수동 시각 변경 직후에는 타이머 실행 또는 창 복귀 시점에 맞춰진다. 창이 계속 보인 채 절전에서 깨어났을 때의 지연은 실제 위젯에서 확인한다.

## 확인할 것

- 같은 달의 자정, 월말, 연말, 날짜를 뒤로 조정하는 경우에 기존 표시가 지워지고 보이는 새 오늘 칸에 표시가 붙는다. 새 오늘 칸이 없으면 기존 표시만 지워진다.
- 개인 월간·주간, 나란히 보기, 열람, 과제 월간·주간, 근태 일간에서 오늘 표시와 기존 접근성 이름이 맞는다.
- 갱신 전후 칸과 초점 요소가 동일하고, 선택일과 보기 범위가 유지된다. 편집 창을 열거나 달력 칸을 누르는 도중에도 확인한다.
- 보임과 포커스가 연달아 와도 타이머는 하나다. 날짜 갱신 자체에서 서버 조회나 알림 전송이 발생하지 않는다.
- 실제 위젯에서 트레이 복귀와 자정을 넘긴 절전 복귀를 확인한다.
