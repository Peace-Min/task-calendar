# 「내 일정 겹쳐보기」 다시 그리기 — 기획서

> 2026-10-01 · 대상 v0.19.x · 파이프라인 **기획 → 개발 → QA → 위키** 의 1단계 산출물. 개발·QA 의 정본.

## 0. 요구

사용자: 타인 일정을 볼 때의 「내 일정 겹쳐보기」가 **허접하고 조잡해 보인다** — 실제 상용 캘린더와 비교해서 다시.

## 1. 지금 모습(2026-10-01 캡처 · 이웅빈 님 6월)

| 문제 | 어디서 보이나 |
|---|---|
| 내 일정이 **점선 테두리 · 채움 없음** 상자 — 끌기 잔상·빈 자리처럼 보여 미완성 느낌 | 격자 칩 · 상세 카드 |
| 남의 칩과 내 칩이 **시간순으로 뒤섞여** 한 칸이 어지럽다 | 6/11 · 6/19 · 6/22 칸 |
| 범례가 글자 한 줄 「---- 점선 = 내 일정」, 작은 체크박스와 밀도 라디오 사이에 끼어 있다 | 열람 띠 |
| **누구 것인지**를 말하는 것이 점선뿐 — 이름·색이 없다 | 전체 |
| 상세 패널도 남·내 카드가 한 목록에 섞이고 내 카드만 점선 | 오른쪽 패널 |
| 겹을 켰는데 체크박스가 꺼진 채로 보이는 경우가 있다(상태와 표시 불일치) | 열람 띠 |

## 2. 상용 캘린더는 어떻게 하나(공통 원칙)

| 제품 | 다른 사람 일정 겹쳐 보기 |
|---|---|
| Google 캘린더 | 캘린더마다 **고유 색**. 왼쪽 목록에 이름+색 칩, 누르면 켜고 끔. 일정은 그 색으로 **채운** 막대. 하루 보기는 사람별 **나란히 보기** |
| Outlook | **겹쳐 보기 모드**: 캘린더마다 색과 **이름 탭**. 앞에 둔 캘린더는 진하게, 나머지는 옅게. 나란히 보기로 바꿀 수 있다 |
| Apple 캘린더 | 캘린더마다 색. 목록의 체크로 켜고 끔. 일정은 **연한 색 채움 + 진한 왼쪽 막대** |

공통 원칙 → 이번 설계의 기준:
1. **색 = 누구 것** — 사람(캘린더)마다 한 색. 점선 같은 "모양"으로 구분하지 않는다.
2. **범례 = 이름 + 색 견본 + 켜고 끄기** 한 덩어리(누르면 토글).
3. **보고 있는 사람이 주인공** — 그 사람 일정은 지금처럼 진하게, 내 일정은 **옅게 깔린 층**.
4. 모양은 같게(같은 칩·카드 틀), 진하기와 색으로만 나눈다.
5. 상세(하루) 보기에서는 **사람별로 묶어** 보여 주고, **시간이 겹치면** 표시한다(약속 잡기의 핵심).

## 3. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| O1 | 범례·토글 | 열람 띠의 체크박스+글자 범례를 **범례 칩 두 개**로 바꾼다: `[■ 이웅빈]`(과제 색 막대 견본 — 꺼지지 않음) · `[■ 내 일정]`(내 색 견본 · **누르면 켜고 끔**, `aria-pressed`). 켜짐/꺼짐이 칩 모양으로 분명히 보인다 |
| O2 | 내 칩 모양 | 점선 상자 → **연한 채움 + 진한 왼쪽 막대**(남의 칩과 같은 틀). 색은 내 전용 토큰(`--mine-*`, 과제 색과 안 겹치는 중립 남색 계열) · 글자는 약간 흐리게 · 제목·시간 그대로 |
| O3 | 칸 안 순서 | 한 칸 안에서 **그 사람 일정 먼저, 내 일정은 그 아래**(사이에 아주 옅은 구분). 시간순은 각 묶음 안에서 지킨다 |
| O4 | 상세 패널 | 선택한 날을 **두 묶음**으로: 「이웅빈 님 일정 (N)」 · 「내 일정 (M)」 머리말. 내 카드도 같은 틀(연한 채움+왼쪽 막대) |
| O5 | 시간 겹침 | 선택한 날 **시간 있는 일정끼리 겹치면** 두 카드에 「시간 겹침」 표시(겹친 상대 시간 함께). 격자에서는 그날 칸 날짜 옆에 작은 겹침 점(툴팁 「시간이 겹치는 일정이 있습니다」) |
| O6 | 상태 동기화 | 겹 켜짐/꺼짐과 범례 칩 표시가 늘 같다(저장값·프로그램 호출·클릭 어느 경로든) |
| O7 | 다크·테마 | 모든 새 색은 토큰 · 라이트/다크/포레스트/세피아/고대비 대비 AA |
| O8 | 지키는 것 | 내 겹은 지금처럼 **일정만**(할 일·커밋 안 보냄) · 읽기 전용 · 「+N」 계산·밀도 규칙 그대로 · 남의 칩 모양 그대로 |

## 4. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| R1 | 내 칩·카드에 점선 테두리가 없다 · 연한 채움 + 왼쪽 막대 | 계약 + 실 위젯 캡처 |
| R2 | 범례 칩 두 개(이름·견본) · 「내 일정」 칩 클릭으로 켜고 끔 · `aria-pressed` 일치 | jsdom + 실 위젯 |
| R3 | 칸 안에서 남 → 내 순서 | jsdom |
| R4 | 상세 패널 두 묶음 머리말과 개수 | jsdom + 실 위젯 |
| R5 | 시간 겹침 표시(카드·칸 점) — 겹치는 경우만 | jsdom |
| R6 | 상태·표시 불일치 없음(O6) | jsdom |
| R7 | 테마 5종 대비(loop-ui-visual peer 화면) | loop-ui-visual |
| R8 | 기존 열람 루프·스위트 무회귀(loop-peer-frame 의 겹 켜고 끄기 시험 포함) | strict · run-loops |

## 5. 범위 밖

- 여러 사람 동시 겹치기.
