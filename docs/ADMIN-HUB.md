# '⚙ 관리' 화면(관리자 허브)과 '내 과제' 이름 정정 기획서

> 2026-10-02, 대상 v0.19.x. 파이프라인(기획, 개발, QA, 위키)의 1단계 산출물로, 개발과 QA 의 정본이다.
> 프로토타입: `dist/rehearsal/admin-proto/index.html` 의 **B′ 수정안**(2026-10-02 사용자 선택, `?nav=B2`).

## 0. 요구와 결정

- 사용자: 관리자가 구성원과 과제를 편집하려면 '과제 관리', '공식 과제', 아래 줄 버튼 순서로 **흩어진 곳을 깊이** 들어가야 한다. 상용 앱이나 추천 방식은? (관리자 1~2명, 가끔 씀)
- 결정(2026-10-02):
  1. 관리 기능을 **한 화면 '⚙ 관리'** 로 모은다. 입구는 3곳(☰ 위젯 메뉴, 사용자 정보, 내 과제)이고 **툴바에는 두지 않는다.**
  2. 화면 구조는 **B′**: 위쪽 묶음 선택 버튼 둘(👥 사람 / 📁 회사 과제), 왼쪽에 그 묶음 항목, 오른쪽에 내용. **선택 표시는 accent 한 가지**이고 회색은 상태에 쓰지 않는다(이전 B안의 회색 혼동을 사용자가 지적했다).
  3. 툴바 '과제 관리'를 **'내 과제'** 로 바꾼다(내 캘린더의 과제 목록이지 회사 과제 편집이 아니다).

## 1. 지금(코드 기준)

| 기능 | 지금 길 | 모달 |
|---|---|---|
| 구성원 등록, 수정, 퇴사, 순서 | 사용자 아이콘 → 사용자 정보 → '구성원 편집' | `#userAdminModal` |
| 직급·소속 | 구성원 편집 → '직급·소속 관리' | `#orgTitleModal` |
| 퇴사자 | 구성원 편집 → '퇴사자 휴지통' | `#trashModal`(퇴사자 범위) |
| 공식 과제 | 🏷️ 과제 관리 → '공식 과제(DB) 찾아보기' 카드 | `#officialModal`(과제 관리 **위에 겹쳐** 뜸) |
| 발주처, 구분·상태, 삭제된 과제 | 공식 과제 → 아래 줄 버튼 | `#customerModal`, `#codeModal`, `#trashModal` |

## 2. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| H1 | 관리 화면 | 새 모달 '⚙ 관리': 머리에 `⚙ 관리`, `관리자 · <내 이름>`, ✕. 그 아래 **묶음 선택 버튼 둘**(`role="tablist"`): **👥 사람**(직원, 조직, 직급) / **📁 회사 과제**(공식 과제 원본(DB), 기준 정보). 그 아래 **왼쪽 항목 목록과 오른쪽 내용** |
| H2 | 항목 | 👥 사람: **👤 구성원, 🏢 직급·소속, 🚪 퇴사자** / 📁 회사 과제: **📁 공식 과제, 🏭 발주처, 🏷️ 구분·상태, 🗑 삭제된 항목**(과제, 발주처, 구분, 상태의 휴지통). 항목마다 오른쪽에 개수를 둔다(알 수 있을 때만. 모르면 비워 두고, 개수를 얻으려고 새 조회를 만들지 않는다) |
| H3 | 선택 표시(B′) | 묶음 버튼: 고른 쪽은 accent-soft 채움, accent 테두리, accent 글자, 컬러 아이콘. 안 고른 쪽은 채움 없음, 흐린 글자, 흑백 아이콘. 왼쪽 목록 바탕은 오른쪽 내용과 같은 패널색(구분은 선). 맨 위에 지금 묶음 이름(accent). 고른 항목은 accent-soft, 왼쪽 accent 막대, accent 글자. **회색 채움을 선택/비선택 표시에 쓰지 않는다.** 오른쪽 위 위치 줄은 '👥 사람 › 👤 구성원' |
| H4 | 내용은 지금 화면 | 각 항목의 내용은 **지금 있는 모달의 내용 그대로**(기능, 문구, 검사, 호스트 명령 불변). 관리 화면 안에서 뜨되 창 위에 창이 겹쳐 보이지 않게 한다(지금의 과제 관리 위 공식 과제 겹침 해소). 구현 방식은 개발이 정한다. 단 **기존 모달 id, 공개 함수(openUserAdmin, openOrgTitle, openTrash, openOfficialModal …), 내부 요소 id 는 그대로 동작**해야 한다(시험과 루프 다수가 그 선택자를 쓴다: `tests/loop-user-admin · loop-trash · loop-org-title · loop-ui-integrity · loop-ui-visual · loop-category-order` 등). 권장: 기존 모달을 관리 화면의 오른쪽 칸에 도킹한다(같은 DOM 과 id 를 유지하고, 자기 배경이나 겹침 없이 그 칸 크기로) |
| H5 | 기억 | 다시 열면 **마지막 항목**이 열린다. 묶음 버튼을 바꾸면 **그 묶음에서 마지막 항목**으로 간다(`localStorage`, 이 PC, 계정별 키 `tc_adminLast:<login>` 등). 이상값이면 구성원 |
| H6 | 입구 ① ☰ 위젯 메뉴 | 제목줄 ☰ 메뉴에 '⚙ 관리' 항목과 '관리자' 꼬리표. **관리자(edit_role=admin)로 확인된 때만** 보인다(모르면 숨김). 마지막 항목으로 열린다 |
| H7 | 입구 ② 사용자 정보 | '구성원' 줄의 '구성원 편집'을 **'⚙ 관리' 카드**로 바꾼다: `⚙ 관리 열기`(마지막 항목)와 그 옆 지름길 `구성원 편집`(구성원 항목으로 열기). 관리자가 아니면 지금처럼 둔다(호스트 거절 한 줄, 공개 문 규칙 유지, 2026-09-18) |
| H8 | 입구 ③ 내 과제 | '🏷️ 내 과제' 창의 '📁 공식 과제 찾아보기' 카드는 **모든 사용자에게 그대로**(찾아보기, 내 캘린더에 추가). 관리자에게만 그 아래 **'⚙ 공식 과제 편집은 관리에서 ›'** 버튼을 둔다. 누르면 내 과제 창을 닫고 관리 화면의 공식 과제 항목을 연다 |
| H9 | 공식 과제 창의 관리 버튼 | 찾아보기로 연 공식 과제 창(관리자)의 아래 줄 '발주처 관리', '구분·상태 관리', '휴지통'은 **관리 화면의 해당 항목으로 연다**(겹쳐 띄우지 않는다). 새로고침과 닫기는 그대로 |
| H10 | '내 과제' 이름 | 툴바 버튼(라벨, aria-label, title), ⋯ 접기 항목, 모달 제목('🏷️ 내 과제'와 부제 '내 캘린더에서 쓰는 과제(색, 순서, 버전관리 연동)'), 사용설명서(#helpModal)의 버튼 이름 언급을 '내 과제'로 바꾼다. **기능 변화 없음** |
| H11 | 좁은 창 | 왼쪽 목록 대신 묶음 버튼 아래 **고르기 상자**(그 묶음 항목만). 묶음 버튼은 둘 다 한 줄(설명 줄은 숨기고 이름은 줄바꿈하지 않는다) |
| H12 | 키보드와 접근성 | 묶음 버튼 ←/→, 왼쪽 목록 ↓/↑, Enter/Space. Esc 는 관리 화면을 닫는다(안에 뜬 확인창이 있으면 그것부터). 열면 고른 항목 버튼에 포커스, 닫으면 연 입구로 포커스가 돌아온다. inert 규칙을 확인한다(2026-10-02 사람 고르기에서 실측한 함정: 모달 머리로 옮긴 요소가 inert 를 물려받았다) |
| H13 | 지키는 것 | 권한 판정은 지금처럼 **호스트**(DB 쓰기 관문), 새 호스트 명령 없음, 일반 사용자 화면 변화는 이름(내 과제)뿐, 테마 토큰만(5종 대비 AA), DB 문자열은 textContent, 기존 모달 단독 호출도 계속 동작(시험과 루프 호환) |

## 3. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| R1 | 관리 화면 구조(H1, H2), 묶음 전환, 항목 전환, 위치 줄 | jsdom + 실 위젯 |
| R2 | B′ 선택 표시: 고른 묶음/항목만 accent, 안 고른 쪽에 회색 채움 없음, 왼쪽 목록 바탕은 패널색 | jsdom(계산 스타일) + 실 위젯 캡처 |
| R3 | 각 항목 내용이 기존 화면과 같은 기능(목록, 편집 버튼, 검색 등), 겹침 없음, 기존 모달 id/함수 호환 | jsdom + 기존 스위트 무회귀 |
| R4 | 기억(마지막 항목, 묶음별 마지막, 계정별, 이상값) | jsdom |
| R5 | 입구 ①②③: 관리자만 보이고 동작한다. 일반 사용자는 ☰ 와 내 과제에 관리 항목이 없다. 사용자 정보는 공개 문 규칙 유지 | jsdom + 실 위젯 |
| R6 | 공식 과제 창 아래 줄 관리 버튼이 관리 화면 해당 항목을 연다(겹침 없음) | jsdom |
| R7 | '내 과제' 이름이 툴바, ⋯, 모달, 사용설명서에 있고 기능은 그대로 | jsdom + 정적 |
| R8 | 좁은 창 고르기 상자, 묶음 버튼 한 줄 | 실 위젯(창 폭) |
| R9 | 키보드, 포커스(열기/닫기/복귀), inert 없음(실 위젯) | jsdom + 실 위젯 |
| R10 | 실 DB: 관리 루프(loop-user-admin, loop-trash, loop-org-title ×5 seed) 무회귀, 관리 화면 경유로 구성원 편집과 발주처 1회(가역, zz 접두, 원복) | run-loops + 확장 |
| R11 | 테마 5종 대비, 기존 스위트와 루프 무회귀 | strict, run-loops |
