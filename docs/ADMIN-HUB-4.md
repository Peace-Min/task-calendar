# '⚙ 관리' 4차 기획서: 사용 개수 배지 정리, 순서는 ▲▼ 로 통일, 직급/소속과 구분/상태 항목 분리

> 2026-10-06, 대상 v0.19.x, 파이프라인은 기획, 개발, QA, 위키 순. 앞 단계 [`ADMIN-HUB-3.md`](ADMIN-HUB-3.md)(45f3a00) 위에 얹는다.

## 0. 사용자 지적과 결정(2026-10-06)

| # | 지적 | 결정 |
|---|---|---|
| 1 | 관리 화면 직급·소속 줄 끝의 `n명 · 하위 n개`가 의미 없고 난잡하다 | 줄의 **사용 개수 배지를 없앤다**. 그 정보가 하던 일(숨김이 왜 꺼졌는지 알려 주기)은 꺼진 [숨김] 버튼의 툴팁과 aria-describedby 로 옮긴다. 같은 결의 배지가 구분, 상태, 발주처 목록에도 있으면 같은 규칙을 따른다 |
| 2 | 관리 화면은 ▲▼ 버튼으로 순서를 바꾸니 과제(내 과제)도 그렇게 통일한다. 드래그가 더 난잡하다 | '내 과제'의 ✥ 손잡이와 끌기를 없애고 **▲▼ 버튼**으로 바꾼다(관리 화면 직급·소속 줄과 같은 컴포넌트, 같은 자리: 줄 오른쪽, 이름/수정 버튼 앞) |
| 3 | 직급·소속, 구분·상태를 한 항목(탭)으로 합치지 말고 각각 나눈다 | 왼쪽 항목: 👥 사람은 **구성원, 직급, 소속, 휴지통**, 📁 회사 과제는 **공식 과제, 발주처, 구분, 상태, 휴지통**. 관리 화면 안에서는 그 화면 안의 [직급 \| 소속], [구분 \| 상태] 전환 버튼을 숨긴다 |

## 1. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| N1 | 배지 제거 | 직급·소속(`#orgTitleModal`) 줄의 `0명`, `1명 · 하위 4개` 배지를 없앤다(단독, 도킹 모두). 구분·상태(`#codeModal`)와 발주처(`#customerModal`) 줄에 '과제 n건' 같은 사용 개수 배지가 있으면 같이 없앤다 |
| N2 | 이유는 버튼으로 | [숨김]이 꺼진 줄: 버튼 `title` 에 "재직자 3명과 하위 조직 2개가 있어 숨길 수 없습니다"처럼 **구체적 이유**를 단다(지금 배지에 있던 숫자를 문장으로). `aria-describedby` 로 같은 문장을 화면낭독기에 준다. 마우스 없이도 알 수 있게 꺼진 버튼도 포커스를 받는다(aria-disabled 패턴). 지금 있는 상단 안내 줄("재직자나 하위 조직이 있으면 숨길 수 없습니다")은 그대로 둔다 |
| N3 | 내 과제 ▲▼ | ✥ 손잡이, 끌기(포인터, 슬롯, 자동 스크롤, Esc), `data-pointer-focus` 코드를 없앤다. 각 줄 오른쪽에 **▲ ▼**(직급·소속 줄과 같은 버튼 클래스, 크기, 간격)를 두고 그다음에 수정, 삭제/제거를 둔다. 맨 위 ▲와 맨 아래 ▼는 비활성(`aria-disabled` 와 이유 툴팁 "맨 위입니다"). 누르면 한 칸 이동하고 저장은 1회. 포커스는 옮겨진 줄의 같은 버튼에 두고, 끝에 닿으면 반대 버튼으로 옮긴다. aria-live 안내는 유지한다. 잠금(오프라인) 중에는 아무것도 바뀌지 않고 기존 토스트를 띄운다(CATEGORY-ORDER 계약 그대로) |
| N4 | 항목 분리 | AH_ITEMS: `orgtitle` 을 **`title`(🏷 직급)과 `unit`(🏢 소속)** 두 항목으로, `codes` 를 **`section`(구분)과 `status`(상태)** 두 항목으로 나눈다. 각 항목은 같은 모달을 도킹하되 **해당 탭으로 열고**, 도킹 중에는 모달 안 탭 전환 버튼을 숨긴다(머리 제목도 '직급'/'소속'/'구분'/'상태'). 개수는 직급 n, 소속 n, 구분 n, 상태 n(이미 있는 데이터만 쓰고 새로 조회하지 않는다). 단독 모달(관리 밖에서 직접 연 경우)은 지금처럼 탭 전환을 유지한다 |
| N5 | 기억과 호환 | 마지막 항목 기억 키에 옛 값(`orgtitle`, `codes`)이 남아 있으면 각각 `title`, `section` 으로 읽는다. 루프와 시험이 쓰는 옛 항목 id 는 별칭으로 받아 준다(`openAdminHub('orgtitle')` 는 직급) |
| N6 | 휴지통 | 사람 휴지통 탭 이름 [구성원, 소속, 직급]은 그대로 두고, 왼쪽 항목 순서에 맞춰 [구성원, 직급, 소속]으로 재배열한다 |
| N7 | 지키는 것 | 새 호스트 명령 없음, 권한은 호스트가 판단, 테마 토큰 사용, DB 문자열은 textContent, 관리 화면 동작(1~3차)은 그대로 |
