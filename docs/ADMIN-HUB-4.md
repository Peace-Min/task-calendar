## 0. 사용자 지적 · 결정(2026-10-06)

| # | 지적 | 결정 |
|---|---|---|
| 1 | 관리 화면 직급·소속 줄 끝의 「n명 · 하위 n개」가 의미 없고 난잡하다 | 줄의 **사용 개수 배지 제거**. 그 정보가 하던 일(숨김이 왜 꺼졌는지)은 **꺼진 [숨김] 버튼의 툴팁 + aria-describedby** 로 옮긴다. 같은 결의 배지가 구분·상태·발주처 목록에도 있으면 같은 규칙 |
| 2 | 관리 화면은 ▲▼ 버튼으로 순서를 바꾸는데 과제(내 과제)도 그렇게 통일 — 드래그가 더 난잡 | 「내 과제」의 **✥ 손잡이·끌기 제거 → ▲▼ 버튼**(관리 화면 직급·소속 줄과 **같은 컴포넌트·같은 자리**: 줄 오른쪽, 이름/수정 버튼 앞) |
| 3 | 직급·소속 / 구분·상태를 한 항목(탭)으로 합치지 말고 각각 분리 | 왼쪽 항목: 👥 사람 = **구성원 · 직급 · 소속 · 휴지통** / 📁 회사 과제 = **공식 과제 · 발주처 · 구분 · 상태 · 휴지통**. 관리 화면 안에서는 그 화면 안의 [직급 \| 소속] · [구분 \| 상태] 전환 버튼을 숨긴다 |

## 1. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| N1 | 배지 제거 | 직급·소속(`#orgTitleModal`) 줄의 「0명」「1명 · 하위 4개」 배지를 없앤다(단독·도킹 모두). 구분·상태(`#codeModal`)·발주처(`#customerModal`) 줄에 「과제 n건」 같은 사용 개수 배지가 있으면 같이 없앤다 |
| N2 | 이유는 버튼으로 | [숨김] 이 꺼진 줄: 버튼 `title` = 「재직자 3명 · 하위 조직 2개가 있어 숨길 수 없습니다」처럼 **구체적 이유**(지금 배지에 있던 숫자를 문장으로) · `aria-describedby` 로 같은 문장(화면낭독기) · 마우스 없이도 알 수 있게 꺼진 버튼에 포커스 가능(aria-disabled 패턴) — 지금 있는 상단 안내 줄(「재직자나 하위 조직이 있으면 숨길 수 없습니다」)은 유지 |
| N3 | 내 과제 ▲▼ | ✥ 손잡이 · 끌기(포인터·슬롯·자동 스크롤·Esc) · `data-pointer-focus` 코드 제거. 각 줄 오른쪽에 **▲ ▼**(직급·소속 줄과 같은 버튼 클래스·크기·간격) → 그다음 수정 · 삭제/제거. 맨 위 ▲ · 맨 아래 ▼ 비활성(`aria-disabled` + 이유 툴팁 「맨 위입니다」) · 누르면 한 칸 이동 · 저장 1회 · 포커스는 옮겨진 줄의 같은 버튼(끝에 닿으면 반대 버튼) · aria-live 안내 유지 · 잠금(오프라인) 중 무변화 + 기존 토스트(CATEGORY-ORDER 계약 그대로) |
| N4 | 항목 분리 | AH_ITEMS: `orgtitle` → **`title`(🏷 직급) · `unit`(🏢 소속)**, `codes` → **`section`(구분) · `status`(상태)**. 각 항목은 같은 모달을 도킹하되 **해당 탭으로 열고** 도킹 중엔 모달 안 탭 전환 버튼을 숨긴다(머리 제목도 「직급」/「소속」/「구분」/「상태」). 개수: 직급 n · 소속 n · 구분 n · 상태 n(이미 있는 데이터만 — 새 조회 금지). 단독 모달(관리 밖에서 직접 연 경우)은 지금처럼 탭 전환 유지 |
| N5 | 기억·호환 | 마지막 항목 기억 키에 옛 값(`orgtitle`·`codes`)이 남아 있으면 각각 `title`·`section` 으로 읽는다. 루프·시험이 쓰는 옛 항목 id 는 별칭으로 받아 준다(`openAdminHub('orgtitle')` → 직급) |
| N6 | 휴지통 | 사람 휴지통 탭 이름 [구성원 · 소속 · 직급] 은 그대로(왼쪽 항목 순서와 맞춰 [구성원 · 직급 · 소속] 으로 재배열) |
| N7 | 지키는 것 | 새 호스트 명령 없음 · 권한은 호스트 · 테마 토큰 · DB 문자열 textContent · 관리 화면 동작(1~3차) 그대로 |
