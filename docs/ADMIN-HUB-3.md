| # | 지적 | 결정 |
|---|---|---|

## 1. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| M1 | 관리 공식 과제는 편집만 | 도킹된 `#officialModal` 에서 숨긴다: 상세의 '＋ 캘린더에 추가', '✓ 추가됨', '제거', 목록 이름 옆 ✓(내 캘린더에 있음 표시), 내 캘린더에 든 줄의 왼쪽 accent 막대. 남는 것: 검색, 필터, 목록, 상세, 새 공식 과제, 편집, 숨김, Excel, 새로고침. 단독(찾아보기)은 지금 그대로 둔다(이 표시들이 주인공이다) |
| M2 | 회사 과제 휴지통 | 왼쪽 항목 이름 '삭제된 항목'을 **'🗑 휴지통'** 으로 바꾼다(위치 줄도). 안 내용(과제, 발주처, 구분, 상태 탭과 복구, 영구 삭제)은 그대로 |
| M3 | 사람 휴지통 | 왼쪽 항목 '🚪 퇴사자'를 '🗑 휴지통'으로 바꾼다. 탭은 **[구성원, 소속, 직급]**. 구성원 탭은 지금의 퇴사자 휴지통 그대로(복구, 기록 0건 계정 영구 삭제)에 안내 한 줄 "퇴사 처리한 구성원입니다. 복구하면 다시 로그인·명부 대상이 됩니다"를 더한다. 소속·직급 탭은 **숨긴 소속·직급 목록과 복구**(지금 직급·소속 화면의 복구와 같은 호스트 명령, 같은 규칙: 상위가 숨김이면 복구할 수 없고 이유를 보인다). 영구 삭제는 없다. 탭 안에 안내 한 줄 "소속·직급은 지난 기록이 이름을 가리키므로 영구 삭제하지 않습니다" |
| M4 | 직급·소속 화면 | 숨긴 항목을 **목록에서 뺀다**(지금은 '숨김' 배지와 복구 버튼으로 남는다). 이 화면에는 쓰는 항목과 '숨김' 버튼만 둔다. 숨기면 "휴지통으로 옮겼습니다. 복구는 🗑 휴지통에서 할 수 있습니다" 토스트 |
| M5 | 이름 일관 | 사용자에게 보이는 '퇴사자 휴지통', '삭제된 항목' 문구를 '휴지통'으로 바꾼다. 구성원 편집의 '퇴사자 보기' 체크와 '퇴사 처리' 동작 이름은 그대로 둔다(동작 이름은 사실대로). 사용설명서 언급도 갱신한다 |
| M6 | 내 과제 순서는 끌기 | '등록된 과제' 각 줄의 **▲▼ 버튼을 없앤다**. 줄 왼쪽에 **✥ 손잡이**를 둔다(SVG 네 방향 화살표, 글자 기호 금지, 늘 흐리게 보이고 줄에 올리면 진하게, `cursor: grab`/끄는 중 `grabbing`, 툴팁 "끌어서 순서 바꾸기") |
| M7 | 끄는 동작 | 포인터로 손잡이를 끌면 그 줄이 떠서(그림자) 따라온다. **놓일 자리에 accent 선**을 긋는다(Atlassian 패턴). 놓으면 그 자리로 옮기고 잠깐 accent 로 강조(drop flash)한 뒤 원래 색으로 돌아온다. 목록 밖이나 같은 자리에 놓으면 아무것도 안 바뀐다. 끄는 중 목록이 길면 위/아래 끝에서 자동 스크롤한다. Esc 로 끌기를 취소한다 |
| M8 | 키보드와 접근성 | 손잡이는 버튼이다(`aria-label` "<과제명> 순서, N번째. 위/아래 화살표로 옮깁니다"). 포커스 후 **↑/↓ 로 한 칸** 옮긴다(Home/End 로 맨 위/맨 아래는 선택). 옮긴 뒤 포커스는 옮겨진 줄의 손잡이에 둔다. `aria-live` 는 "<과제명>: 3번째에서 2번째로 옮겼습니다" |
| M9 | 저장과 규칙 | 옮기기는 지금의 순서 저장 경로를 쓴다(`moveCategory` 와 같은 저장, saveState 1회, 보고서, 필터, 선택 상자가 따른다. CATEGORY-ORDER 계약 그대로). 끌기로 여러 칸을 한 번에 옮겨도 **저장 1회**. 서버 끊김(잠금) 중에는 손잡이가 비활성이고 지금과 같은 잠금 토스트를 띄우며, 순서와 화면은 바뀌지 않는다 |
| M10 | 지키는 것 | 새 호스트 명령 없음(복구는 직급·소속 화면이 이미 쓰는 명령), 권한 판정은 호스트, 테마 토큰만, DB 문자열은 textContent, 관리 화면 동작(ADMIN-HUB, ADMIN-HUB-2)은 그대로. 구성원 편집의 '순서 편집'은 이번 범위 밖 |
