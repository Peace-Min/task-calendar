# 날짜 줄 배치 C: 주간 제목도 월, 과제 필터는 [월간 | 주간] 옆

상태: 구현 완료(2026-10-30, 브랜치 `feat/nav-c`, f563165), 0.25.0 판에 실림. 실제 위젯(1920px)과 브라우저(1000, 720, 520px, 어둡게)에서 월간 주간 전환, 9월 12월 전환 때 [주간] 단추와 과제 단추 이동 0px 확인. 시안 `dist/proto/nav-layout-ab.html` 의 C 카드, `dist/proto/filter-in-nav.html`.

## 1. 배경

- 월간에서 주간으로 바꾸면 제목이 "2026년 10월" 에서 "2026년 10월 26일 ~ 11월 1일" 로 길어져, 제목 오른쪽 [월간 | 주간] 단추가 177~429px 밀린다. 누른 단추가 손 밑에서 도망간다. 과제 탭도 같다("10월 26일 ~ 11월 1일").
- 과제 필터가 탭 줄 아래 한 줄(42px)을 단추 하나와 칩에 쓴다.

## 2. 결정 (2026-10-30 사용자)

1. **주간 제목도 월.** 그 주 월요일이 든 달로 "2026년 10월"(구글, 애플 캘린더 방식, 근태 주간보고 주 이름 규칙과 같다). 달이 걸친 주도 그 달 하나. 주의 날짜는 표 머리(월 26, 화 27 …)에 있다. 개인 탭, 다른 사람 일정 창, 과제 탭 모두.
2. **제목 칸 최소 폭은 재서 정한다.** 1월부터 12월까지 "YYYY년 M월" 을 실제 글꼴로 재서 가장 긴 폭. 숫자를 박지 않는다. 글꼴 크기가 바뀌면(좁은 폭 규칙) 다시 잰다. 그래서 월간 주간 전환, 9월 12월 전환에서 오른쪽 단추가 0px 움직인다.
3. **과제 필터는 날짜 줄의 [월간 | 주간] 바로 오른쪽, 고정 위치.** 필터 줄(`#filterbar` 한 줄)은 없앤다. 개인 탭과 다른 사람 일정 창 모두. 과제 탭은 왼쪽 과제 목록이 필터라 단추가 없다.
4. **좁은 폭용 배치 바꾸기는 만들지 않는다.** 날짜 줄은 넘치면 다음 줄로 내려가게(줄바꿈 허용)만 한다. 필터 단추는 글자에 맞추되 최대 폭에서 말줄임. 600px 기준의 단추 폭 바꾸기는 없앤다.
5. 칩은 지금처럼 남는 자리를 재서 보이고 넘치면 `+N`, 자리가 없으면 칩을 감춘다(단추 글자가 상태를 말한다).

## 3. 하지 않는 것

- DB, 호스트, 버전은 그대로. 월 선택 팝업(`#jumpMonth`)과 이동 규칙(주간 7일)은 그대로.
- 다른 단추들이 좁은 폭에서 잘리는 문제는 이번 범위가 아니다.
