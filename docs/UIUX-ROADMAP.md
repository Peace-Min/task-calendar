# UI/UX 로드맵 (앱 전반)

> 출처: `ui-ux-eval-loop` 5-비평가 + 적대적 검증 (2026-07-08, run wf_3590c902).
> 계기: "보고서 서식바(.rpt-fmt)" 마감 패스를 요청했으나, 워크플로가 **앱 전체**를 평가함.
> **서식바 자체는 무결점 통과** — 앱 토큰(`--line-2`·`--r-sm`·`--fs-meta`·`--panel`·`--accent`)만으로 지어져 P0/P1/P2 어디에도 없음. 아래는 그 김에 나온 **앱 전반** 개선안.

## ⚠️ 먼저 읽기 — 적대적 검증 요지 (착수 전 필독)
평가의 자가 검증이 상위 항목 다수를 **이미 해결됨/과장**으로 교정함. 헛수고 방지:

- **P0 아이콘(이모지→SVG)은 사실상 이미 완료.** `applyIcons()`(L4237, `bind()` L4433에서 무조건 호출)가 상단바/패널 이모지를 전부 단색 SVG(`ICON` 객체 L4203-4235: search/tag/bug/palette/doc/download/folder…)로 런타임 교체함. HTML의 이모지(L936-940 등)는 **JS 로드 전 폴백**. → 남은 진짜 잔여는 **도움말/변경사항 본문(prose)의 이모지뿐**(L1351·1403·1464·1504·1582-1598·3165). 이걸로 재스코프.
- **P0 칩 클리핑도 대부분 이미 방지됨.** 현재 칩은 시각=`flex:none`, 제목=`flex:1`+말줄임(CSS L205-208)이라 `17:0` 클리핑 안 남. **유효한 신규분은 선행 0 제거(09:00→9:00)·정시 '17시' 축약뿐**(S 공수). "셀<110px면 시각 숨김"은 380px에서 **모든 시각을 숨겨** 북극성("한눈에 오늘·일정 스캔")과 충돌 → 채택 금지 또는 ~40px로 재조정.
- **P0 대비(AA)는 진짜지만 미완 스펙.** `--accent-text`/`--danger-text`/`--faint-text` 값이 light/forest/sepia **3테마만** 제시됨. **6테마 전부**(+ `html.dark` L868-878, `contrast` L905) 재매핑 필수 — `:root`만 정의하면 다크 패널에 다크 텍스트로 새 AA 실패.
- **P1 타이포**는 숨은 전역 밀도 변경. `--fs-emph` 폐기+본문 13은 `--fs-emph` 전 소비자(본문 L30·.btn L94·.menu L124)에 영향, `--fs-micro:11`을 12로 올리면 **380px 칩을 오히려 키움**(P0 칩과 상충). 수치 확정 후.
- **P1 히트타겟 24px**는 `fitChips`의 `MOREH=17`(L2647)과 충돌 → 상수 동반 갱신 필요.
- **P1 오늘/선택**은 의도적 이전 결정 되돌림(L189 주석: "꽉 찬 파랑 폐기 → 선택과 충돌"). 재도입 시 인지하고.
- **P1 주(Week) 보기**는 380px 위젯에서 7열×시간축 = 열폭 ~45px로 사용 불가. → **앱/큰창 모드 한정** 또는 day-panel 비례 타임라인으로 대체.
- **누락 평가**: 빈/에러/성공 상태, 다크·고대비 테마의 새 토큰 검증, 300px 폭. 착수 시 함께 볼 것.

## 디자인 토큰 권고
- **간격**: `--sp-1..6`(4/8/12/16/24/32) 이미 존재 → 새로 만들지 말고 강제. 준-흰색 hex ~8종(#f7f8fb·#f8f9fc·#fafbfd·#f6f8fc·#f1f3f8)을 `--hover-bg`(#f3f5fa)로 통합, `.cell.dim`용 `--wash` 1개만 추가 → 다크모드 수동 오버라이드(L880-901) 축소.
- **타이포**: 12/13/15/18/22로 넓히되 `--fs-micro:11` 유지(칩). 위계=크기+굵기(굵기 단독 금지). 22px 월제목(L79) → `--fs-display` 토큰.
- **색**: 인터랙티브 **텍스트** 역할 분리 — `--accent-text`(forest #1f7a50, sepia #8f4a1f=기존 `--accent-2` 재사용), `--danger-text` #c0343a, `--faint-text`→#626a7d. `--accent`(#3e5be0)/#d6494e는 채움·밑줄 등 **비텍스트** 전용. **6테마 전부 정의**.
- **반경/그림자**: `--r-sm 6`/`--r-md 10`/`--r-lg 14` + `--shadow` 단일 — 유지, 컴포넌트 raw 리터럴 금지.
- **밀도**: '테두리 그룹핑'→'여백 그룹핑'. `.grid` 1px 격자를 옅은 틴트/주경계만으로, per-row 박스(.set-opt·.rcard)를 여백+헤어라인 divider로.

## 북극성
단색 아이콘 한 벌·전 테마 AA·시간축을 갖춰, 380px 바탕화면 위젯에서 클릭 없이 한눈에 오늘·일정·빈 시간대를 읽는, Linear/Google Calendar와 나란히 둬도 '내부 툴' 티가 안 나는 캘린더.
