# 개인 일정과 다른 사람 일정의 월간, 주간 보기

상태: 구현 완료(2026-10-30, 브랜치 feat/peer-week). 시안 `dist/proto/personal-peer-week-rows.html`.

## 1. 배경

- 과제 탭에는 [월간 | 주간]이 있고, 주간은 왼쪽에 과제를 나열한 과제별 줄 표다.
- 개인 탭과 다른 사람 일정 창은 월간 날짜 격자만 있었다. 처음 구현(codex, 4316c53)은 주간을 "월간 한 줄을 크게" 그렸는데, `+N` 접힘이 줄 뿐 새로 보이는 정보가 없었다.
- 주간은 "이번 주 과제마다 무엇을 했나"를 보는 자리다. 근태 주간의 과제투입시간, MM 과 같은 관점이다.

## 2. 결정 (2026-10-30 사용자)

1. **월간은 날짜 격자 그대로, 주간만 과제별 줄 표.** 왼쪽 과제 이름 칸 + 월요일부터 일요일까지 7칸. 막대 모양(일정 실선, 할 일 점선, 내 일정 남색)은 월간과 같다.
2. **빈 과제도 늘 보인다**(과제 탭 주간과 같다). 분류 없는 기록은 맨 아래 "분류 없음" 줄(기본 과제 "기타" 와 이름이 겹치지 않게).
3. **다른 사람 일정, 겹쳐 보기**: 같은 DB 과제(공식 과제, id `db-<uid>` 가 같다)면 상대 과제 줄 안 아래 차선에 내 막대를 둔다. 겹치지 않는 내 과제(다른 DB 과제, 개인 과제)는 굵은 선 아래 내 과제 줄(이름 칸 남색 바탕)로 둔다. 내 일정 겹을 끄면 둘 다 빠진다.
4. **나란히 보기도 주간에 둔다.** [겹쳐 | 나란히] 단추가 월간, 주간에 따라 사라지지 않게 한다. 규칙은 겹쳐 보기와 같다: 같은 DB 과제를 위에 두고 왼쪽(상대)과 오른쪽(나)의 차선 수를 맞추며, 각자만 가진 과제는 굵은 선 아래(맞추지 않는다).
5. 보기 선택은 창마다 따로 기억한다(`tc_calView`, `tc_peerView`, 기본 월간). ◀ ▶ 와 PageUp, PageDown 은 주간에서 7일씩. 제목은 주 범위(`2026년 10월 26일 ~ 11월 1일`).

## 3. 구현

- `renderGrid`: 주간이면 `renderWeekRows(#grid, 'all' | 'peer')`, 나란히 보기면 `renderWeekRows(#gridMine, 'mine')`. 월간은 `renderMonthBars` 그대로(주간 갈래를 걷었다).
- `renderWeekRows`: 표 안에 날짜 머리(`.wr-hd`, 키보드 포커스는 여기만)가 있고 `#weekdays` 는 주간에서 감춘다. 줄마다 `.gridrow[data-from]` 과 `.cell[data-date]`, 막대는 `barChipHtml` 이라 누르기, 끌어 옮기기(날짜만 바뀐다), 날짜 고르기가 월간과 같은 코드로 돈다. `+N` 접힘은 없다(줄이 내용만큼 늘고 표가 스크롤된다).
- 내 일정 겹의 과제: `buildMineOverlay(entries, cats)` 가 `_cat {key, name, color}` 를 싣는다(공식 `db-<uid>`, 개인 `m:<id>`). `categoryId` 는 그대로 null 이라 필터바 축은 바뀌지 않는다. 빈 내 과제도 줄로 보이도록 메인 창이 겹 끝에 `{ _mineCats }` 한 칸을 붙이고, 열람 창(`pvMineGet`)이 떼어 `meta.mineCats` 로 프레임에 넘긴다(호스트 C# 은 그대로 배열만 옮긴다).
- 주간에서 방향키로 다른 주로 넘어가면 선택 날짜가 따라가므로 오른쪽 상세도 다시 그린다(`focusGridDate`).

## 4. 하지 않는 것

- DB, 호스트 명령, 버전은 바꾸지 않는다.
- 과제 탭의 주간과 보고서는 그대로다.
- 내 겹에 메모, 할 일 등 일정 밖의 것을 싣지 않는다(과제 이름과 색만 더했다).
