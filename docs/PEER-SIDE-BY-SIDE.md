# 다른 사람 일정 보기 — 「나란히 보기」 모드 — 기획서

> 2026-10-02 · 대상 v0.19.x · 파이프라인 **기획 → 개발 → QA → 위키** 의 1단계 산출물. 개발·QA 의 정본.
> 앞 단계: [`PEER-OVERLAY-REDESIGN.md`](PEER-OVERLAY-REDESIGN.md)(겹쳐 보기 다시 그리기 · 2026-10-01).

## 0. 요구

사용자: Outlook 처럼 **그 사람 캘린더와 내 캘린더를 동시에 띄우는** 방식이 겹쳐 보기보다 합리적일 수 있다 — 「나란히 보기」 모드를 추가.

## 1. 결정(2026-10-02 대화)

| 항목 | 결정 |
|---|---|
| 모드 | **[겹쳐 보기 \| 나란히 보기]** 두 가지. Google 식 사람별 열(하루 시간축)은 이 앱에 하루·주 보기가 없어 범위 밖 |
| 기본 | **겹쳐 보기**(지금 그대로) · 고른 모드는 열람 창에만 기억 |
| 이유 | 겹쳐 보기 = 같은 칸에서 "둘 다 비었나"(약속 잡기 · 시간 겹침 표시). 나란히 보기 = 그 사람 달력을 **섞이지 않은 채** 보며 내 달과 큰 흐름 비교(Outlook 기본 방식) |

## 2. 상용 참고

| 제품 | 나란히 보기 |
|---|---|
| Outlook(클래식) | 캘린더마다 **이름 탭 + 색** 이 붙은 달력을 좌우로. 탭의 화살표로 겹쳐 보기 ↔ 나란히 보기 전환. 날짜 이동은 모든 달력이 **같이** 움직인다 |
| Google | 하루 보기에서 사람별 열(이름·사진 머리말) — 시간축이 같은 높이로 맞는다 |

약점(Outlook 월 보기 캡처에서 확인): 달력 폭이 절반이 돼 칩 글자가 거의 안 읽힌다 → 아래 S4·S5 로 보완한다.

## 3. 목표 동작

| # | 항목 | 동작 |
|---|---|---|
| S1 | 모드 전환 | 열람 띠에 **분할 버튼 `[겹쳐 보기 \| 나란히 보기]`**(`role="radiogroup"` 또는 `aria-pressed` 버튼 둘). 저장 키 `tc_peerLayout` = `'overlay'`(기본) \| `'side'`. 값이 이상하면 `'overlay'`. **열람 창에만** 적용(내 화면 무관 · 내 키와 따로) |
| S2 | 두 달력 | 나란히 보기면 달력 영역이 **왼쪽 = 그 사람**, **오른쪽 = 내 일정** 두 달력. 각 달력 위에 **이름 탭**: 왼쪽 「▮▮▮ ○○ 님」(과제 색 견본), 오른쪽 「▮ 내 일정」(내 색 `--mine-*` 견본). 각자 요일 머리줄을 가진다 |
| S3 | 내용 나누기 | 왼쪽 = 그 사람 기록(일정·기간·반복·할 일 — 겹쳐 보기 왼쪽 묶음과 같은 것) · 오른쪽 = **내 겹 일정만**(지금 겹과 같은 범위: 할 일·커밋 없음). 오른쪽 칩은 겹쳐 보기의 내 칩과 같은 모양(연한 채움 + 왼쪽 막대) · 남/내 구분선은 없다(한 달력에 한 사람) |
| S4 | 줄 맞춤 | 두 달력의 **같은 주(週) 줄은 같은 높이**(높은 쪽에 맞춤). 밀도 고정·촘촘히·펼침 모두. 창 크기가 바뀌어도 다시 맞춘다 |
| S5 | 폭 확보 | 나란히 보기에서는 오른쪽 **상세 패널을 접어** 두 달력이 폭을 나눠 쓴다. 날짜를 누르면 상세 패널이 **아래에서 올라오는 시트**로 열리고(좁은 화면의 기존 시트 동작 재사용 가능), 닫기 손잡이로 닫는다 |
| S6 | 함께 움직임 | 달 이동(‹ › 오늘)·날짜 선택은 **두 달력에 같이** 반영(선택 테두리 양쪽). 어느 달력의 칸을 눌러도 같은 날짜 선택 |
| S7 | 상세 | 시트의 일정 상세는 겹쳐 보기와 같다 — 「○○ 님 일정 (N)」 · 「내 일정 (M)」 두 묶음 + 시간 겹침 배지 |
| S8 | 시간 겹침 점 | 나란히 보기에서도 그날 시간이 겹치면 **두 달력의 그 칸 모두**에 주황 점 |
| S9 | 겹 토글과의 관계 | 나란히 보기에서는 오른쪽 달력이 곧 내 일정이라 범례의 「내 일정」 켜고 끄기 칩은 **감춘다**(또는 비활성 + 툴팁). 겹쳐 보기로 돌아오면 원래 `tc_peerOverlay` 값 그대로 |
| S10 | 좁은 창 | 열람 창 폭이 좁아 달력 하나가 너무 좁아지면(기준은 개발이 정함 · 대략 달력 하나 < 420px) **위아래로** 쌓는다(위 = 그 사람 · 아래 = 나). 줄 맞춤은 좌우일 때만 |
| S11 | 지키는 것 | 읽기 전용(오른쪽 달력에도 끌기·편집·새 기록 없음) · hpost 봉인 · 과제 필터는 **왼쪽(그 사람)** 에만 · 밀도 규칙 그대로 · 겹쳐 보기 화면은 바이트 단위로 지금과 같음(모드 기본값일 때 회귀 없음) · 키보드 방향키 이동은 왼쪽 달력 기준(오른쪽 칸은 클릭 선택) |
| S12 | 다크·테마 | 새 색은 모두 토큰 · 테마 5종 대비 AA |

## 4. 수용 기준(QA)

| ID | 기준 | 확인 |
|---|---|---|
| R1 | 분할 버튼으로 모드 전환 · `tc_peerLayout` 저장 · 다시 열어도 유지 · 이상값 → 겹쳐 보기 · 내 창(`PEER` 아님)에는 버튼 없음 | jsdom + 실 위젯 |
| R2 | 나란히 보기: 달력 두 개 · 이름 탭 두 개 · 왼쪽에 `_mine` 칩 0 · 오른쪽에 `_mine` 아닌 칩 0 | jsdom + 실 위젯 |
| R3 | 같은 주 줄 높이 일치(±1px) — 고정·펼침 각각, 창 크기 변경 뒤에도 | 실 위젯 |
| R4 | 상세 패널 접힘 → 날짜 클릭 시 시트 열림 · 두 묶음 머리말 · 닫기 | jsdom + 실 위젯 |
| R5 | 달 이동·날짜 선택이 양쪽 동기(오른쪽 칸 클릭 → 양쪽 `.sel`) | jsdom |
| R6 | 시간 겹침 점이 양쪽 칸에 | jsdom |
| R7 | 나란히 보기에서 「내 일정」 토글 칩 감춤 · 겹쳐 보기 복귀 시 `tc_peerOverlay` 보존 | jsdom |
| R8 | 좁은 폭에서 위아래 쌓기 | 실 위젯(창 폭 조절) |
| R9 | 읽기 전용 · 아무것도 안 나감 — loop-peer-frame 에 나란히 보기 라운드 추가(열고 닫기 반복에도 DB·로그 무변화) | loop-peer-frame |
| R10 | 테마 5종 대비 · 기존 스위트·루프 무회귀(겹쳐 보기 기본값 화면 동일) | strict · run-loops · 실 위젯 대비 측정 |

## 5. 범위 밖

- Google 식 하루·주 **사람별 열**(시간축) — 하루·주 보기가 생길 때.
- 셋 이상 동시 보기(여러 사람).
- 내 창(메인 화면)의 나란히 보기.
