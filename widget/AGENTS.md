# 근태 보고 작업 전 확인

근태, 일간보고, 주간보고, Netcus 연동 및 보고 기록 DB를 변경하기 전에 [보고 정책 정본](../docs/ATTENDANCE-REPORT-POLICY.md)과 루트 [AGENTS.md](../AGENTS.md)를 반드시 읽는다.

- 회사 성공을 확인한 후에만 DB에 쓴다. 관련 DB 변경은 하나의 트랜잭션이다.
- 어느 단계든 실패하면 공통 실패 안내와 입력 유지, 재시도는 회사 요청부터 실행한다.
- DB 전용 재시도, 보고 작성본 DB 선저장, 로컬 복구 큐 및 자동 동기화를 추가하지 않는다.
- 회사 전송 성공만으로 전체 완료를 알리거나, 폼 채우기만으로 제출 성공을 기록하지 않는다.
- `node tests/audit-attendance-policy.mjs`로 회귀를 확인하고 실제 회사 시험과 모의 시험을 구분해 기록한다.
