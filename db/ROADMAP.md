## 권장 진행 순서

1. ✅ **완료**: **P1 인증 스텁(JIT 프롬프트)** + **P3 앱↔DB 연동(P3.1~P3.5)** — 읽기·캐시·CRUD·카탈로그·재연결·단일 스토어까지 localhost에서 구현·실증.
2. ✅ **완료**: **P4 Excel 추출기**(자체 템플릿 v2 — 기존 장표 서식 추종 폐기, 사용자 승인 2026-07-22). 보고서 집계 정책은 P4 후속으로 남김.
3. **실 Excel 확보되면**: **P2**(스키마 검증) 먼저 → 이상 없으면 P5(정식 이관).
4. **실사용자 배포 전**: **P6.5**(스텁 → app_user·netcus 인증 위임 + 최소권한 계정).
