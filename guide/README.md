# 사용 영상 v4 배포

영상 판: `2026-10-25-core-v4` (2026-10-25).

- 전체 소개: 개인 캘린더와 과제 공용 캘린더의 기본 흐름
- 내 과제 등록: 일반 과제 등록 및 공식 과제 참여
- 개인 일정과 할 일: 등록, 수정, 완료, 삭제
- 과제 공용 일정: 등록, 수정, 최근 변경, 개인 일정에 복사, 삭제

월간보고 및 보고서 작성은 이번 기초 사용 영상에 포함하지 않는다.
영상 안에 설명이 있으므로 v4에는 별도 자동 자막 SRT를 배포하지 않는다.
재생 목록의 정본은 `guide.json`이다. 빌드는 `guide.json` 이 가리키는 영상(과 같은 이름의 srt)과 `guide.json` 만 내보낸다(이 README 는 나가지 않는다).

## 폐쇄망에서 pull 후 배포

1. `feat/db-app`의 최신 커밋을 pull한다. 영상은 Git에 포함되어 있으므로 별도 릴리스 파일 다운로드가 필요 없다.
2. 저장소 루트에서 아래 명령을 실행한다. 기존 `installer/배포-빌드.cmd`로 빌드해도 영상 판 변경을 감지한다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File installer/publish-update.ps1 -Build -Guide
   ```

3. 생성된 `dist/installer/guide/`의 v4 MP4 네 개를 기존 앱이 참조하는 공유 업데이트 폴더의 `guide/`에 복사한다. `guide.json`은 마지막에 복사한다.
4. 기존 앱에서 사용 영상 창을 닫았다가 다시 열어 네 영상과 재생을 확인한다.

## 이번 변경의 범위

앱 버전 `0.23.0`, 앱 코드와 설치 구성, DB 구조 `17`은 변경하지 않는다.
`installer/guide-shipped.txt`는 배포 산출물 생성에 사용한 영상 판과 앱 버전 기록만 갱신한다.
Setup.exe는 같은 앱 소스로 재빌드되며 새 가이드는 Setup.exe 외부의 `guide/` 폴더로 생성된다.
따라서 **Setup.exe만 실행해서는 가이드 영상이 바뀌지 않는다.**

영상만 갱신할 때 기존 사용자의 앱 재설치나 DB 작업은 필요 없다.
빌드가 함께 생성한 `release-v0.23.0.sql`, `latest.json`, Setup.exe는 이번 영상 갱신만을 위해 기존 배포본에 덮어쓰거나 실행하지 않는다.
이 산출물은 앱 자체를 다시 배포할 때 쓰는 파일이다. 재빌드한 Setup.exe의 바이너리 해시는 기존 배포본과 다를 수 있다.
