# 사용 영상 v5 배포

영상 판: `2026-11-02-core-v5` (2026-11-02, 앱 0.25.0 화면).

- 전체 소개: 개인 캘린더, 과제 공용 캘린더, 근태 탭
- 내 과제 등록: 내 과제 창(한 상자 목록)과 과제 추가 창으로 일반 과제와 공식 과제 더하기
- 개인 일정과 할 일: 날짜 고르기, 새 기록, 수정, 과제 필터(다중 선택), 할 일, 삭제
- 과제 공용 일정: 참여자, 등록(종일, 매주 반복), 수정, 최근 변경, 날짜 목록, 개인 일정에 등록, 삭제(이 날짜만)
- 근태 보고(새 영상): 근태 탭 달력, 일간 근태 창(과제 블록, 시간, 메모, 미리보기), 주간보고 목록과 편집

회사 사이트로 보내는 단추(일간 보고, 주간 보고, 인트라넷에서 확인)는 영상에서 누르지 않고 가리키며 설명만 한다.
월간보고와 보고서 창은 이번 영상에 포함하지 않는다.
영상 안에 자막이 들어 있으므로 v5에도 별도 자막 SRT를 배포하지 않는다.
재생 목록의 정본은 `guide.json`이다. 빌드는 `guide.json` 이 가리키는 영상(과 같은 이름의 srt)과 `guide.json` 만 내보낸다(이 README 는 나가지 않는다).

## 폐쇄망에서 pull 후 배포

1. `feat/db-app`의 최신 커밋을 pull한다. 영상은 Git에 포함되어 있으므로 별도 릴리스 파일 다운로드가 필요 없다.
2. 저장소 루트에서 아래 명령을 실행한다(배포 담당이 한다).

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File installer/publish-update.ps1 -Build -Guide
   ```

3. 생성된 `dist/installer/guide/`의 v5 MP4 다섯 개를 기존 앱이 참조하는 공유 업데이트 폴더의 `guide/`에 복사한다. 공유 폴더에 남은 v4 MP4 는 지운다. `guide.json`은 마지막에 복사한다.
4. 기존 앱에서 사용 영상 창을 닫았다가 다시 열어 다섯 영상과 재생을 확인한다.

## 이번 변경의 범위

영상 파일과 `guide.json` 만 바뀐다. 앱 코드와 설치 구성, DB 구조는 바꾸지 않는다.
따라서 **Setup.exe만 실행해서는 가이드 영상이 바뀌지 않는다.**
`installer/guide-shipped.txt`(마지막으로 내보낸 영상 판 기록)는 이 작업에서 고치지 않았다. 배포 빌드가 영상 판 차이를 보고 고친다.
