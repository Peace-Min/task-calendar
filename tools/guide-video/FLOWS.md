# 실제 앱에서 확인한 흐름 (가이드 영상 v2, v3, 이슈 #13)

확인 환경: 설치형 0.22.0(`%LOCALAPPDATA%\Programs\TaskCalendar\수행과제캘린더.exe`, `TC_DEBUG_PORT=9222`), 로컬 MySQL `taskcalendar` 판번호 13,
`db/demo/demo-db.cmd -Load` 로 넣은 데모 데이터. 확인 날짜 2026-10-19. 화면은 메인 창 최대화(웹 영역 1920x1032, 배율 1).
v2 때 녹화 계정은 관리자 권한이었다(내 과제 창에 '관리자' 꼬리표가 붙은 지름길이 보였다). v3 는 데모 DB 안에서만 녹화 계정을 일반 사용자(edit_role viewer)로 바꿔 찍었고, 그 지름길(`#catAdminRow`)이 보이지 않는다.
주의: 앱은 지난 실행의 관리자 기억(`localStorage` 의 `tc_adminSeen:<login>`)으로 지름길을 먼저 보이고, 호스트에 권한을 물은 뒤에야 숨긴다. 녹화 전에 내 과제 창에서 지름길이 없는지 확인한다.

## 0. 이슈 #13 이 가정한 순서와 다른 점

| 이슈의 가정 | 실제 앱 | 영상에서의 처리 |
|---|---|---|
| "DB 과제(공식 과제)" 와 "일반 과제(개인 과제)" | 화면 이름은 **공식 과제(DB)** 와 **개인 과제**. 목록에서는 공식 과제에 `DB` 배지, 개인 과제는 배지 없음. 휴가, 기타는 `기본` 배지가 붙은 개인 과제 | 자막은 "공식 과제(DB 과제)", "일반 과제(개인 과제)" 를 함께 쓴다 |
| "공식 과제를 불러오고 검색, 선택해 내 과제에 편입/연결" | 버튼 이름은 **＋ 캘린더에 추가**. 누르면 내 과제 목록에 들어오고 상세에 "추가됨" 과 [제거] 가 뜬다. 인증이나 별도 권한이 필요 없다(내 캘린더 데이터만 바뀐다, `offSubscribeFromCatalog`) | "캘린더에 추가" 그대로 보여 준다 |
| 공식 과제 마스터의 등록과 편집은 별도 권한 | 맞다. 내 과제 창에서 연 '찾아보기' 는 모두에게 읽기 전용이고(＋ 새 공식 과제, 편집, 숨김이 감춰짐), 편집은 '⚙ 관리' 의 공식 과제(관리자 전용)에서 한다 | 영상에서 열지 않는다. 자막으로만 구분한다 |
| "기존 과제 재연결" | 개인 과제로 쓰던 일정과 할 일을 공식 과제로 옮기는 별도 도구(내 과제 창 아래 🔗). 처음 쓰는 사람의 흐름에는 필요 없다 | 다루지 않는다 |
| 날짜 선택 뒤 일정 등록 | 날짜 칸을 누르면 오른쪽 패널(일정 상세)이 그 날짜를 따른다. 패널의 **＋ 추가** 는 그 날짜로 '빠른 캡처' 를 연다 | 이 순서 그대로 |
| 일정 수정 | 패널 카드의 **수정** 이 같은 빠른 캡처를 편집 모드로 연다 | 그대로 |
| 할 일 추가, 완료, 복원 | 패널 **할 일** 탭의 **＋ 할 일 추가**(빠른 캡처의 할 일 모드). 체크하면 '이 날 완료' 구획으로 가고, 다시 누르면 돌아온다 | 그대로 |

## 1. 내 과제 창 (과제 유형과 추가)

열기: 툴바 `#btnCatsTop` "내 과제"(좁은 창에서는 `⋯ → 내 과제`). 창 `#categoryModal`, 제목 "🏷️ 내 과제 / 내 캘린더에서 쓰는 과제(색, 순서, 버전관리 연동)".

위에서부터
1. `#btnOfficialOpen` **📁 공식 과제(DB) 찾아보기** 카드(오른쪽에 "8건, 연결됨 →").
2. `#catAdminRow` "⚙ 공식 과제 편집은 관리에서 › 관리자"(관리자에게만 보임, 영상에서는 누르지 않음).
3. "등록된 과제 / 개인과 공식(DB) 통합 목록", `#catList` 행 `.cat-row`(이름, `DB` 또는 `기본` 배지, 건수, ▲▼, 옮기기, 수정, 제거/삭제).
4. 추가 폼: `#cName`(과제 이름, 예: 주간 보고서), `#cPalette .swatch[data-color]`(색상 18개 + 직접 고르기), `#cDesc`(설명, 선택). (버전관리 연동 카드는 2026-10-26 Git, SVN 기능과 함께 없어졌다.)
5. 아래 줄: `#btnRelinkOpen` 🔗 기존 과제 재연결, 닫기, `#btnCatSave` **과제 추가**.

개인 과제 추가 = 이름 입력, 색 고르기, (설명), **과제 추가**. 목록 끝(기본 과제 앞이 아니라 등록 순서 끝)에 새 행이 생긴다.

## 2. 공식 과제(DB) 찾아보기와 연결

`#btnOfficialOpen` 을 누르면 창 `#officialModal` "📁 공식 과제 (DB)  연결됨 (8건)".
- 검색 `#offSearch`(사업명, 통상명칭, 발주처), 필터 `#offCustomer` `#offSection`, 그리고 상태 체크박스 묶음 `#offStChecks`(상태마다 `input[data-offst]` 하나, 기본은 모두 켜짐). 끈 상태만 목록에서 빠지고, 끈 것은 이 PC 에 기억되어 재연결 고르기(`#rlpStChecks`)에도 같이 적용된다. (옛 상태 드롭다운과 '진행중만'은 2026-10-26 에 없어졌다.)
- 목록 `#offList .off-row[data-id]`, 구분(선진행, 일반계약, 사업부관리)별 묶음. 이미 내 과제인 것은 이름 옆 ✓.
- 행을 누르면 오른쪽 `#offDetail`: 사업명, 계약명, 발주처, 구분, 상태, 계약기간, 개발종료, 그리고 **`[data-offadd]` ＋ 캘린더에 추가**.
- 누르면 토스트 "'(예시) 품질 관리 시스템 고도화'을(를) 캘린더에 추가했습니다", 상세는 "✓ 추가됨 [제거]" 로 바뀌고 내 과제 목록에 `DB` 배지로 들어온다.
- 권한: 연결(캘린더에 추가, 제거)은 누구나. 공식 과제 원본의 새로 만들기, 편집, 숨김은 관리 화면(관리자)에서만.

영상에서 쓰는 값: 검색어 "품질", 대상 "(예시) 품질 관리 시스템 고도화"(녹화 계정이 아직 연결하지 않은 진행중 과제).

## 3. 과제 목록과 필터

- 메인 화면 "과제 필터:" 줄(`#filterbar` 의 `.fchip`)에 내 과제가 순서대로 보인다(전체, 각 과제와 건수).
- 할 일 탭 위에도 같은 과제 칩 줄이 있다.
- 빠른 캡처의 과제 상자 `#qaCat` 도 같은 목록이다.

## 4. 날짜, 일정 등록과 수정

- 날짜 칸 `.cell[data-date="YYYY-MM-DD"]` 의 `.cell-top` 을 누르면 선택(칩을 누르면 미리보기가 열리므로 칸 위쪽 숫자 줄을 누른다).
- 오른쪽 패널 `#dayPanel`, 탭 `#dptab-detail` 일정 상세, `#dptab-todo` 할 일(`#dptab-git` 커밋 내역은 2026-10-26 삭제).
- 일정 상세 머리의 `#btnAddHere` **＋ 추가** 를 누르면 빠른 캡처 `#quickAdd`(일정 모드)가 열린다.
  `#qaTitle` 일정 제목, `#qaDate`(고른 날짜가 들어 있음), `#qaCat` 과제(기본 '기타'), `#qaAllDay` 종일, 시간 `#qaStartH` `#qaStartM` `#qaEndH` `#qaEndM`,
  미리알림(없음, 놓침 방지, 직접), `#qaMore` "장소, 반복, 기간, 메모 ▾", `#qaSave` **추가**.
  과제, 시간 상자는 네이티브 `<select>` 라 녹화에서는 펼치지 않고 값을 바꾸고 change 이벤트를 보낸다(펼친 목록은 별도 창이라 화면 캡처에 안 잡힌다).
- 수정: 패널 카드 `.card` 의 `[data-act=edit]` **수정** 을 누르면 같은 빠른 캡처가 편집 모드로 열린다(저장 단추 `#qaSave`).

## 5. 할 일

- `#dptab-todo` 탭의 `#btnTodoNew` **＋ 할 일 추가** 를 누르면 빠른 캡처(할 일 모드): `#qaTitle` "할 일 (짧게)", `#qaDate`, `#qaCat`, `#qaMemo` 설명, `#qaEndDate` 기간 종료일, `#qaPrio` 중요, `#qaSave` 추가.
- 행 `.todo-row[data-id]`: `.todo-check[data-act=toggle]` 완료 표시, `.todo-text` 누르면 수정, ☆ 중요, ✕ 삭제.
- 완료하면 '이 날 완료' 구획(`.nd-sec[data-sec=done]`, 접혀 있으면 눌러 펼친다)으로 옮겨지고 취소선. 다시 체크하면 '이 날' 로 돌아온다.

## 6. 다른 사람 일정 보기 (독립 창)

- 입구: 툴바 `#btnPeerPick` "다른 사람 일정" 을 누르면 사람 고르기 팝오버: `#pkSearch`(이름, 직급, 조직으로 찾기), 탭 `#pkTabPeople` 사람 / `#pkTabOrg` 조직도,
  구획 ★ 즐겨찾기, 최근 본 사람, 내 부서(SW 3팀 13명). 행 `[data-act=open][data-login]`, 별 `[data-act=star]`.
- 사람을 고르면 **별도 창**(PeerWindow, CDP 대상 url `?peerwin=1`, 창 제목 "김철수 님의 일정")이 뜬다. 일반 Windows 틀(최소화, 최대화, 닫기).
  처음 크기 1400x900(웹 영역 1384x861), 자리는 PC 에 하나 기억한다(`widget.settings.json` 의 `Peer`, 최대화 여부 포함).
- 창 머리: `#pvSwitch` ▾ 사람 바꾸기, `#pvFav` ☆ 즐겨찾기. 본문은 iframe(`?peer=1`) 안의 열람 달력:
  `겹쳐 보기` / `나란히 보기`(`.seg-b`), `#peerOverlayToggle` 내 일정, 밀도 라디오 `input[value=fixed|dense|expand]`(고정, 촘촘히, 펼침), 월 이동, 검색, 과제 필터, 오른쪽 패널(그 사람 일정과 내 일정 구획, 시간 겹침 표시).
- 읽기 전용: 편집하려 하면 "읽기 전용 보기라 여기서는 바꿀 수 없습니다".
- 펼침은 칸이 내용만큼 늘고 넘치면 달력이 스크롤된다(0.22.0 수정).
- 열람 범위: 녹화 계정은 같은 팀(SW 3팀) 동료를 볼 수 있다. 데모 데이터에서 일정이 있는 사람은 김철수, 이영희, 박민수뿐이다.

## 7. 보고서(보고서 작성 가이드 v3, scripts/report.mjs)

`#btnReportTop` "보고서" 를 누르면 `#reportModal` "보고서 초안": 일간 작성, 주간 작성, 기간 취합 탭. 주간 작성은 회사 주간보고 모양의 미리보기가 나온다.
**`#btnRptSend`(📤 일간보고 전송, 📤 주간보고 작성)와 '내용 출처: netcus 일간' 은 회사 사이트에 접속하므로 누르지 않는다.**

일간 작성(날짜 `#rptFrom`, 일간은 하루, 미래 날짜는 고를 수 없다)
- 미리보기 머리 `[data-rview=card]` **카드** / `[data-rview=doc]` **글 편집**(일간 기본은 카드).
- 카드 `.rcard[data-rcat]`: 시간 칸 `.rcard-h-in`(change 때 저장, 캘린더의 날짜별 과제 시간), `.rcard-x` **×**(이 보고서에서 빼기). 빼면 흐리게 남고 "이 보고서에서 뺌 `.rcard-back` 되돌리기", 시간이 있으면 안내 토스트(info).
- 글 편집: 잠긴 머리 줄 `.rdoc-lock`(`[과제] : 시간`), 내용 칸 `.rdoc-ta[aria-label="<과제> 내용"]`, 고치면 **초안으로**, 위쪽 **모두 초안으로**.
- 왼쪽 **보고서 묶음** `#rptGroupOpen` **설정**: 창 `#rptGroupModal`, 줄 `.rgm-row[data-dr=1]` 을 포인터로 끌어 다른 줄 위에 놓으면 묶인다(`.rgm-row.kid`). 내용 없는 과제는 "오늘 내용 없는 과제 n개 `[data-gmore]` 보기" 아래에 접혀 있다. 요약 `#rptGroupSum`("자료 정리 → 기타", 앱 화면 문구).
- `#btnRptCopy` **복사**: 토스트 "보고서를 클립보드에 복사했습니다".
- 임시 저장: `tc_rptDraft:<who>:<날짜>`(일간), `tc_rptDraftW:<who>:<from>_<to>`(주간). 녹화 뒤 `--restore-local` 이 지운다.

주간 작성(기본 보기 글 편집, 회사 주간보고 작성 폼 모양 `.rwf`)
- 기간, 제목(`.rwf-ro`, "기간에 따라 자동", 고칠 수 없음), 진행사항(`.rdoc-ta[data-wsec]`, aria-label "<과제> 진행사항"), 과제투입시간 `.rwd-hours`(읽기 전용, 일간 시간 합계),
  미처리사항, 문제점 및 건의사항, 회의내용(`.rwf-off` "회사 화면에서 직접 씁니다"), 차주계획(aria-label "<과제> 차주계획").
- 날짜를 고르면 그 주 월요일부터 일요일로 맞춰진다. 내용 출처는 '캘린더 기록' 그대로 둔다.

## 8. 녹화 중 주의

- 이 PC 의 브라우저 저장소에 **실제 이름이 든 '최근 본 사람'**(`tc_peerRecent:<login>`)이 있었다. 녹화 전에 백업하고 비우며, 끝나면 그대로 되돌린다(record.mjs 가 한다).
- 툴바 '문의' 단추의 툴팁에 실제 메일 주소가 있다. 그 단추 위에서는 커서를 멈추지 않는다.
- 미리알림이 녹화 중에 뜨지 않게 새 일정은 미래 날짜(이번 주 목요일 무렵)에 만든다.
- 로그아웃하지 않는다(세션과 회사 자격증명이 지워진다).
